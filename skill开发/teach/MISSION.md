# Mission: Skill 开发

> 编写与维护本仓库 `skills/` 下的轻量教学 Skill(caveman / grill-me / teach-you 等)。

## Why
- 教学会话常用 Skill 调用提升效率。
- Skill 元数据(SPEC 与 registry)是 Agent 选 skill 的唯一信号。

## Success looks like
- 编写 1 个 Skill 只需复制模板填写 front-matter 与正文。

## Constraints
- Skill 文件名 kebab-case,以 `SKILL.md` 为入口。
- front-matter 必须含 `name` `description`。

## Out of scope
- Skill 内部复杂逻辑(只是 skill 而非 agent)。
