# Mission: 校招笔试+面试《数据结构与算法》冲刺（1-2 个月）

> **2026-08-01 转型**：本课程从"学校期末考试"转向"校招技术面试"。期末版材料（下方「历史材料」）保留为概念背景，但**推进顺序与重点改为面试频率优先**。路线变更记录见 learning-record 0000 + 本文件。

## Why
1-2 个月内通过校招的**笔试 + 技术面**。已经学过 C 语言和基础数据结构（数组/链表/栈/队列），但不熟练——目标是在有限时间内，把"学过但生疏"练成"面试时能在 C 里边讲边写出清晰、基本无错的代码"，并建立**看到题能识别模式（双指针/滑动窗口/DP/…）**的能力。

## Success looks like
- 能在 **C** 中独立写出高频题的清晰代码：数组双指针/滑动窗口、链表反转/环检测、二叉树遍历、二分查找、快排/归并、哈希表（手写或数组模拟）、基础 DP。
- **边讲边写**：能向面试官口述思路、复杂度（时间+空间）、边界处理，而不是闷头写。
- **复杂度分析**：看到任意一段循环/递归能说出大 O，并解释为什么（不是背"嵌套=O(n²)"）。
- **模式识别**：看到一道没做过的题，能判断它属于哪类经典模式（如"求最长无重复子串 → 滑动窗口"）。
- **笔试能力**：能处理 ACM 模式的输入输出（C 的 `scanf`/`printf`、多组数据），在限时内交出可运行代码。

## Constraints
- **时间**：1-2 个月，按面试频率优先推进，跳过低频。
- **主语言：C**（沿用现有材料，零切换成本）。**翻译对照方式**：每题先在 C 写透，同题附 Python/JS/TS 对照版，借 DSA 顺带拓宽这几门语言。
- **C 的硬现实**：无 STL（哈希表/动态数组/优先队列需手写）；部分题 C 版明显更长，对照语言版正好展示"为什么高级语言更适合这类题"。
- **起点**：C 语法 + 数组/链表/栈/队列学过但不熟；非零基础，不重讲语法，但**每个算法仍完整过一遍 C 实现**。
- **历史材料**：`lessons/0001-0020`（期末考试版，按《算法图解》+《啊哈！算法》章节序）作**概念背景**，不按其顺序推进。注意：**生成 ≠ 学会**，这 20 课一节都未验证过理解。

## Confirmed
- 目标：校招笔试 + 技术面（先建通用核心能力，非定向某厂）。
- 时间：1-2 个月。
- 主语言：C + 翻译对照（Python/JS/TS）。
- 决策记录（2026-08-01）：用户原想 C/Python/JS/TS 四门并进；经分析"1-2 月四门并进会稀释面试能力"，改为**聚焦 C + 翻译对照**（详见 learning-record 0000）。

## Out of scope（除非真题出现）
- 竞赛级进阶结构（线段树、树状数组、KMP/AC 自动机、高级字符串算法）。
- 重新从语法教起。
- 把四门语言平等对待、每题各写一遍（稀释精力，已否决）。
