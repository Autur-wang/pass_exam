## 考试/面试边界一句话

**校招笔试 + 技术面**，1-2 个月。两种形态都要练：
- **笔试**：常 ACM 模式，自己处理输入输出（C 的 `scanf`/`printf`）、多组数据、注意时空限制；常考经典算法实现。
- **面试**：常核心代码模式（写一个函数），重在**边讲边写、思路清晰、复杂度分析、代码无大 bug**。
重点：**思路表达 + 模式识别 + 复杂度分析 + C 手写无大错**。不追竞赛级（线段树/KMP 不在范围，除非真题出现）。

## 已知易错点（继承 + 随讲随记）

- **大 O**：嵌套循环≠一定 O(n²)，看内层增量（如 `j*=2` 是 log n）。
- **二分边界**：`left<=right` vs `left<right`、`mid` 更新 ±1，最易写崩。
- **链表**：头/尾/空三类边界；快慢指针起止位置。
- **C 容器**：无现成哈希表/动态数组，部分题要手写（对照 Python 一行解决，正是拓宽语言入口）。
- **DP**：状态定义错则全错；先想"我在哪、我是谁、我从哪来"。
- **通用**（继承 OS 经验）：抽象先给画面再上术语；出题前她常要先澄清，节奏碎、先安抚再问；反复出现"措辞半句"问题，让她口述判据。
