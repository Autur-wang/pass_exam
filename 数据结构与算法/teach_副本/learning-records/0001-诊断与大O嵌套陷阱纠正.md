# 0001 · 摸底诊断 + 大 O"嵌套=n²"陷阱纠正

2026-08-01 摸底两题：① 大 O 分析——把 `for(i)*for(j*=2)` 误判为 O(n²)，没看出内层翻倍是 log n（典型"嵌套=平方"口诀误用）；② "有序数组查找"→选对二分，模式直觉可用。

讲透"数次数法"（嵌套 = 外层次数 × 内层次数；翻倍/减半 = log₂n）后，验证题（外层 n × 内层 `j/=2`）选对 **O(n log n)**，misconception 已纠正。

**Implications**：Phase 0 的 Big O"迭代计数"子技能过关，可推进。但 Big O 另两块——**递归的递推式（时间）**、**调用栈深度（空间）**——留到"递归"课随讲，不单独开。**C 手写基本功（指针/结构体/malloc）待第一道编码题实测**，不假设熟（旧诊断说她"学过但不熟"）。关联 [[MISSION.md]]、[[0000-面试复习主清单]]。
