# ADR-0006: teach 缺件最小可用兜底内容模板

- **Status**: accepted
- **Date**: 2026-07-26
- **Deciders**: 用户 / Agent

## 背景

learn-code / skill开发 / 多媒体 在 verify-scaffold 首跑时 INCOMPLETE, 因 teach/ 缺少必要文件。

## 决策

为 INCOMPLETE 的 teach/ 提供以下 4 文件最小兜底:

### `MISSION.md` 模板

```markdown
# Mission: <课程主题>

> 待填充。

## Why
<为什么学>

## Success looks like
- <验收条件>

## Constraints
- 时间 / 起点 / 资料源

## Out of scope
- <不要教什么>
```

### `NOTES.md` 模板

```markdown
# Notes

## 用户偏好
- <偏好>

## 教学节奏
- <每节课时长 / 节奏选择>
```

### `GLOSSARY.md` 模板

```markdown
# Glossary

## 元术语
- **Lesson**: <本课程最小教学单元定义>

## 已掌握
(暂无)
```

### `RESOURCES.md` 模板

```markdown
# Resources

## Knowledge
- <本地资料 / 在线资料>

## Wisdom (Communities)
- <社区>

## Gaps
- <已知缺口>
```
