四个核心包(贯穿全书)

包管什么依赖
pi-ai只管调模型:统一 30+ 供应商、流式、成本追踪不依赖任何 Agent 概念(最底层)
pi-agent-core只管跑循环:Agent Loop + 工具 + 事件依赖 pi-ai
pi-coding-agent完整 CLI 产品 + SDK 接口依赖上面两层
pi-tui终端 UI 库(差分渲染/组件)正交:与 Agent 体系解耦,可单独复用
