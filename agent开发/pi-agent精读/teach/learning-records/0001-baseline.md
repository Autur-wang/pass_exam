# 基线:课程建立与学习起点

本课(Pi-Agent SDK 深度精读)于 2026-07-21 建立,源为冬瓜《Pi-Agent SDK 深度教程》(10 章拆 pi SDK)。
用户经 AskUserQuestion 明确:**全量建课**(约 32 节)、**TypeScript 轨**。

## 已确立的事实(steer 未来会话)

- **体裁 = 源码精读**,不是刷题课。每节讲「是什么 / 怎么做 / 为什么这样设计」,锚定教程真实代码。
- **grounding 源 = 教程 markdown 本身**(pi 真源码不在库内);忠实转译教程,引教程口径,不自称读过 pi 源码。
- 用户诉求(见 [[MISSION.md]]):看懂生产级 Agent SDK 内部如何运转,乃至基于 SDK 造自己的 Agent。
- 前置知识**尚未探明**:用户对 TypeScript、异步流(`for await`)、事件驱动、LLM API 的熟悉度未知——
  **首次直播授课时先探底**(让她复述 0001 的三重身份+减法哲学,并问她 `for await` 是否眼熟),再定后续深浅。

## 教学起点建议

- 从 **0001**(三重身份+减法哲学,已建为金标准母版)开始直播,先建立「Pi 值得读、且读得完」的动机。
- 前 6 章(0001–0020)是地基,建议顺序通读;第 7 章起进阶可按需跳。
- ch03 Agent Loop(0007–0010)是全课最重、最核心的一章,预留最多讲解时间。

> 说明:约 32 节为**提前储备的素材**,不等于用户已掌握。掌握与否以直播复述/自测表现为准,后续学习记录据此增补。
