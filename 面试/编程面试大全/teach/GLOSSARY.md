# 编程面试 Glossary

本课的标准术语。所有讲解、自测、学习记录都以此为准。中文术语后附英文原文;`避免` 一行列出不推荐的说法或常见混淆。

## 复杂度
**大 O(Big-O)**:
描述算法**最坏情况**下运行时间或空间随输入规模 n 增长的**增长率**,忽略常数与低阶项。
_避免_:「运行了多少秒」「大 O 就是平均情况」。

**摊还分析(Amortized Analysis)**:
把偶发的昂贵操作的代价均摊到一长串操作上,得出单次操作的平均代价。动态数组 push 的摊还复杂度是 O(1)。
_避免_:把摊还 O(1) 说成「每次都 O(1)」。

**原地(In-place)**:
只用 O(1)(或 O(log n))额外空间完成的算法。
_避免_:「不占内存」。

## 数据结构
**动态数组(Dynamic Array)**:
底层是一块**连续内存**、容量满时按倍数扩容的可变长数组。随机访问 O(1),末尾摊还 push O(1)。
_避免_:与「链表」混用「数组」一词;与固定数组(static array)不区分。

**链表(Linked List)**:
由节点通过指针串起的线性结构,节点在内存中**不连续**。头部插入删除 O(1),随机访问 O(n)。
_避免_:「链表访问也是 O(1)」。

**栈(Stack)**:
后进先出(LIFO)的线性结构,只在一端 push/pop。
_避免_:把栈和「调用栈」的语义混为一谈时不加说明。

**队列(Queue)**:
先进先出(FIFO)的线性结构,一端入另一端出。
_避免_:用「栈」泛指所有线性容器。

**哈希表(Hash Table)**:
用哈希函数把键映射到桶来存取的结构,平均 O(1)、最坏 O(n)。
_避免_:「哈希表查找总是 O(1)」;中文里「散列表」是同义词,本课统一叫哈希表。

**二叉搜索树(BST, Binary Search Tree)**:
每个节点满足「左子树全部 < 本节点 < 右子树全部」的二叉树;操作复杂度取决于**树高**。
_避免_:默认 BST 就是平衡的(不平衡时退化为 O(n))。

**堆 / 优先队列(Heap / Priority Queue)**:
用**完全二叉树**(通常存在数组里)实现、满足堆序性质的结构;取极值 O(1)、插入/弹出 O(log n)。
_避免_:把「堆(数据结构)」和内存的「堆(heap 内存区)」混用而不说明。

**字典树(Trie)**:
按字符逐层分叉的树,路径即前缀,用于字符串前缀检索。
_避免_:「前缀树」与「Trie」混用时不统一(本课叫 Trie)。

**并查集(Union-Find / Disjoint Set)**:
维护若干不相交集合、支持 union 与 find 的结构,配合路径压缩 + 按秩合并近似 O(1)。
_避免_:「联合查找」「不相交集」混称——本课统一叫并查集。

## 算法范式
**递归(Recursion)**:
函数调用自身、把问题化为更小的同类子问题;必须有 base case 保证收敛。
_避免_:把递归和「循环」当作可无脑互换。

**回溯(Backtracking)**:
在决策树上系统地尝试并在走不通时撤销选择(剪枝),用于组合/排列/子集类问题。
_避免_:「回溯就是暴力」——回溯的关键是剪枝。

**动态规划(DP, Dynamic Programming)**:
把有**重叠子问题**且满足**最优子结构**的问题,通过定义状态与递推关系、缓存子问题解来求解。
_避免_:把任何用了数组缓存的做法都叫 DP;把 DP 与「分治」混同。

**贪心(Greedy)**:
每步都取当前局部最优,期望得到全局最优——仅在问题具备贪心选择性质时才正确。
_避免_:「贪心一定比 DP 快所以更好」。

**分治(Divide and Conquer)**:
把问题分成独立子问题、分别求解再合并(归并排序、快排)。
_避免_:与 DP 混同(分治子问题**不重叠**)。

## 图
**邻接表 / 邻接矩阵(Adjacency List / Matrix)**:
图的两种表示;邻接表省空间(稀疏图),邻接矩阵查边 O(1)(稠密图)。
_避免_:不分稀疏/稠密就断言哪种「更好」。

**BFS / DFS(广度优先 / 深度优先搜索)**:
图/树遍历的两种策略;BFS 用队列、逐层扩展、可求无权最短路,DFS 用栈/递归、探到底再回退。
_避免_:「BFS 和 DFS 只是顺序不同,效果一样」。

**拓扑排序(Topological Sort)**:
有向无环图(DAG)的线性排序,使每条边都从前指向后;存在当且仅当无环。
_避免_:在有环图上谈拓扑排序。

**最短路 / Dijkstra**:
求带**非负权**图单源最短路径的贪心算法,用优先队列每次取最近未定点。
_避免_:「Dijkstra 能处理负权边」(不能,负权用 Bellman-Ford)。

## 排序
**稳定排序(Stable Sort)**:
相等元素的相对顺序在排序后保持不变(归并稳定,快排/堆排一般不稳定)。
_避免_:「快排是稳定的」。

**比较排序(Comparison Sort)**:
只靠元素两两比较的排序,下界是 Ω(n log n);计数/基数排序不是比较排序,可突破该下界。
_避免_:「所有排序最快都是 O(n log n)」。

## 系统设计
**CAP 定理**:
分布式系统在网络分区(P)发生时,一致性(C)与可用性(A)只能保其一。
_避免_:「CAP 是三选二,平时也要放弃一个」(P 不可放弃,取舍发生在分区时)。

**一致性哈希(Consistent Hashing)**:
把节点和键映射到同一个哈希环上,增删节点时只有相邻区间的键需要迁移。
_避免_:与普通「取模哈希分片」混同。

**分片(Sharding)**:
按某个键把数据水平切分到多台机器以扩展容量与吞吐。
_避免_:「分片=加缓存」。

## 学习法(本 workspace 术语)
**检索练习(Retrieval Practice)**:
主动从记忆里回想而非重读,是把知识从「会了的错觉」转成长期记忆的核心手段。对应每节课的 `🔁 先回忆一下`。
_避免_:「多看几遍就记住了」。

**流畅性 vs 存储强度(Fluency vs Storage Strength)**:
流畅性=当下能顺畅调用(易高估掌握);存储强度=长期能取回(真正目标)。刻意制造「合意困难」才长存储强度。
_避免_:把「看懂了」等同于「掌握了」。
