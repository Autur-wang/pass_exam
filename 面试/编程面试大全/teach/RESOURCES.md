# 编程面试 Resources

> 均取自 `../README-cn.md`(编程面试大学)真实收录的一手来源,或本仓库 `../cheat-sheets/`。课程讲解的知识以这些为准,不用凭记忆的猜测填空。

## Knowledge · 总纲与速查
- [仓库本体:coding-interview-university / 编程面试大学](https://github.com/jwasham/coding-interview-university)
  本课的骨架来源。每个主题的「学什么、看哪条视频」都出自它。Use for:确认某主题是否在面试范围内、拿该主题的精选一手链接。
- [Big-O Cheat Sheet — bigocheatsheet.com](https://www.bigocheatsheet.com/)
  各数据结构/排序的时间空间复杂度一览。Use for:核对复杂度声明,别凭感觉写。本地镜像:`../cheat-sheets/big-o-cheatsheet.pdf`。
- `../cheat-sheets/` 本地 PDF:`bits-cheat-sheet`(位运算 + 2 的幂)、`system-design`、以及 C/C++/Java/Python/STL 语言速查。Use for:临场语法与位技巧回忆。

## Knowledge · 数据结构与算法(视频课)
- [MIT 6.006 Introduction to Algorithms(视频播放列表)](https://www.youtube.com/playlist?list=PLUl4u3cNGP61Oq3tWYp6V_F-5jb5L2iHb)
  哈希表、堆、复杂度的权威讲解(README 多处引用)。Use for:哈希 table doubling、堆与堆排序、摊还分析。
- [Sedgewick & Wayne — Algorithms, Part 1(Coursera)](https://www.coursera.org/learn/algorithms-part1)
  归并/快排/优先队列的经典课(README 排序小节的主推)。Use for:排序族的稳定性、比较器、系统排序。
- [Skiena — CSE373 Analysis of Algorithms(视频)](https://www.youtube.com/watch?v=z1mkCe3kVUA)
  复杂度、图、动态规划的实战讲法(README 复杂度/DP 小节引用)。Use for:Big-O 直觉、DP 递推关系、NP。
- [UC Berkeley CS 61B(archive.org 视频)](https://archive.org/details/ucberkeley_webcast_htzJdKoEmO0)
  链表、排序、优先队列(README 多处引用)。Use for:线性结构与排序的系统讲解。
- [freeCodeCamp:为什么我为了 Google 面试全职自学 8 个月](https://medium.freecodecamp.org/why-i-studied-full-time-for-8-months-for-a-google-interview-cc662ce9bb13)
  仓库作者的动机故事与「75% 原则」出处。Use for:理解这份大纲的取舍逻辑。

## Knowledge · 系统设计
- [The System Design Primer — donnemartin](https://github.com/donnemartin/system-design-primer)
  README 系统设计小节的「从这里开始」。Use for:容量估算、缓存、分片、一致性哈希、CAP、常见设计题范式。
- [CAP 定理的简明英文介绍](http://ksat.me/a-plain-english-introduction-to-cap-theorem)
  Use for:一致性 vs 可用性的取舍表述。

## Wisdom (Communities)
- [LeetCode Discuss](https://leetcode.com/discuss/)
  高信噪比的题解与蓝图(README 的二分/回溯「蓝图」即出自此)。Use for:某题的多种解法与边界讨论。
- [r/cscareerquestions](https://www.reddit.com/r/cscareerquestions/)
  Use for:面试流程、真实经验、平台化的准备策略。
- 现实练习:找同伴做 **mock interview**(轮流当面试官),或用平台约模拟面试。Use for:把「白板表达」这项只能靠真人反馈打磨的技能练出来。
  > 若学习者不想加入社区,在此记录并停止推荐。
