DFS 三种序:前序 / 中序 / 后序

上一课我们说 DFS「一头扎到底」。但「扎到底」的路上,什么时候把当前节点算作『访问』,有三个时机可选——放在处理孩子之前、之间、之后,就得到前序、中序、后序。别把它们当三句要死记的口诀:每一种都对应一类真实需求,尤其那句「BST 的中序遍历得到有序序列」,是后面无数题的钥匙。

先回忆:上一课(树入门与遍历)里,DFS 靠递归(或显式栈)沿一条分支探到底再回退。这节我们不换算法,只调整一件事——在递归里「访问根」这句话插在哪一步。先自己想想:如果把它插在「递归左孩子」和「递归右孩子」中间,访问顺序会有什么规律?

二、每种序各自擅长什么

前序(根 → 左 → 右):根最先被处理,适合「先复制/建立根,再挂上子树」——比如深拷贝一棵树、把树序列化。

中序(左 → 根 → 右):对二叉搜索树(BST)做中序,输出严格递增的有序序列。原因很直白:BST 的不变量是「左子树全部 < 根 < 右子树全部」,而中序正好按「先左、再根、后右」访问,自然升序。这条性质是「BST 找第 k 小」「验证 BST」等题的核心武器,下一课会反复用到。

后序(左 → 右 → 根):根最后处理,适合「必须先拿到孩子的结果,才能算自己」——比如释放/删除整棵树(先删孩子再删自己,否则丢指针)、求树高(先知道左右子树高,取 max+1)。

三、写法:递归三行,迭代靠栈

递归写法几乎就是定义本身,以中序为例:inorder(node){ if(!node) return; inorder(node.left); visit(node); inorder(node.right); }——把 visit 挪到最前是前序、挪到最后是后序。迭代写法要用一个显式栈模拟递归调用栈:中序迭代的套路是「一路压左孩子到底,弹出即访问,再转向其右孩子」。能手写迭代中序,是面试里区分「背过」和「真懂」的分水岭。

四、关键定义

前序 / 中序 / 后序(pre- / in- / post-order)
DFS 的三种访问时机:根在左右孩子之前 / 之间 / 之后被访问。左孩子恒在右孩子之前。
中序有序性(in-order sorted property)
对二叉搜索树做中序遍历,得到的是元素的升序序列。避免误以为对任意二叉树中序都有序——只有 BST 才成立。

五、复杂度

操作平均最坏
任一种序遍历(每节点访问一次)O(n)O(n)
递归栈 / 显式栈空间(= 树高 h)O(h)O(n)

三种序的时间完全一样(都是 O(n)),空间也一样——都吃「当前根到叶那条路径」的深度 h。平衡树 h≈log n;退化成链时 h=n,空间 O(n)。换句话说,选哪种序不影响复杂度,只影响你在什么时机拿到节点。

面试怎么考。遍历序是「重建二叉树」这一高频题族的入口:

  • 给定两个遍历序列,重建原树:中序 + 前序(或中序 + 后序)可唯一确定一棵二叉树。思路:前序的首元素(或后序的末元素)就是根,拿它去中序里一劈,左半是左子树、右半是右子树,递归即可。
  • 「BST 的第 k 小 / 是否有序 / 相邻差最小」:一律先想「中序遍历成升序序列」,题目瞬间线性化。
  • 被追问「光有前序 + 后序行不行」:一般不行——遇到只有单个孩子的节点时无法区分它是左还是右,重建不唯一。

光背「根左右 / 左根右 / 左右根」而不理解,考场上一定会背串。记住锚点:「前/中/后」修饰的永远是『根』被访问的时机,左恒在右前。

更要命的坑:「中序得到有序序列」只对 BST 成立。对一棵普通二叉树做中序,输出就是普通顺序、毫无升序可言。很多同学把这条性质错记成「中序天生有序」,一到非 BST 的题就用错。

沿用上一课的二叉树节点,把三种序都写出递归版与迭代版:

preorder / inorder / postorder 各两版(迭代中序用栈最能体现原理)。再挑战一道经典题:写 build(inorder, preorder),由中序 + 前序重建二叉树,并对建出来的树再跑一遍遍历,验证序列和输入一致。

带走这一条:三种序只差「访问根」这一步插在哪。真正要焊死进肌肉记忆的是——对 BST 做中序 = 升序输出,以及中序 + 前序/后序能唯一重建二叉树。

六、自测题

Q1:单独给你一棵二叉树的中序遍历序列,能唯一确定这棵树吗?

不能。中序只告诉你「根把序列劈成左、右两段」,但没告诉你根是谁,同一个中序序列能对应许多不同形状的树。必须再补一个前序(点名第一个根)或后序(点名最后一个根),才能递归地唯一重建。而且注意:前序 + 后序仍不够——碰到只有一个孩子的节点时无法判定左右,重建不唯一。

Q2:下面哪种遍历能对一棵二叉搜索树(BST)输出从小到大的有序序列?

中序(左 → 根 → 右)。因为 BST 的不变量是「左子树全部 < 根 < 右子树全部」,中序恰好先访问较小的左子树、再访问根、最后访问更大的右子树,自然升序。前序/后序/层序都不具备这个性质。注意前提是「BST」——普通二叉树中序不会有序。
