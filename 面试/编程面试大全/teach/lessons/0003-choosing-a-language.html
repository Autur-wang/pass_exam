面试该用哪门语言

面试白板上,你没有 IDE、没有自动补全、没有 Google。选错语言,常常不是败在算法上,而是败在"这个 API 到底怎么写来着"。这节讲清一个容易被忽视的分工:你学数据结构与算法用的语言,和面试当场写代码用的语言,可以不是同一门——以及,面试语言到底该按什么标准挑。

上一课我们用抽认卡和主动回忆对抗遗忘,目标是"面试当天还能从空白记忆里取回知识"。这一课把同一个逻辑推到语言层面:面试现场临时去翻语法,和记不住知识一样致命。先想一想——你现在最顺手的那门语言,能不能不查文档就写出一个可变数组、一个哈希表的基本用法?

一、两种语言,两种用途

作者把语言问题拆成了两半,这是这节最重要的一个区分:

  • 学 DS&A 的语言:作者主要用 C 和 Python。C 非常底层,让你直接接触指针、内存的分配与释放,从而看清数据结构与硬件的联系——这些细节在 Python/Java 里被隐藏了。Python 则现代、灵活、代码量少,学起来实用。
  • 面试当场用的语言:大公司通常只接受固定的几种。这门语言的首要标准不是"底层不底层",而是"你能不能在白板上把它写对"。

理想情况是两者用同一门语言,这样你只需精通一门(比如通篇用 Python)。但作者也说了,这是个人偏好,你完全可以学习时用 C 摸清底层、面试时换一门写起来更快的语言。二者不必强行绑定。

四、关键定义

学 DS&A 的语言
用来学习数据结构与算法、看清底层的语言。作者用 C(直接操作指针与内存,理解结构与硬件的联系)+ Python(实用、代码少)。避免把"学习用语言"和"面试用语言"当成必须是同一门。
面试语言
在白板或协作编辑器上当场写解法的语言。大公司常见的固定选择是 C++ / Java / Python;JavaScript、Ruby 可能可以但需事先查明限制。
选择原则
选你最熟、能不查语法快速写对、面试官也常见的那一门。避免为了"显得厉害"而选一门自己不熟的语言。

面试怎么考。语言本身几乎从不是考点,但它会成为暗礁:面试官看的是你能否识别问题、选对结构、把复杂度分析清楚、边写边讲。如果你为了炫技选了一门不熟的语言,时间就会耗在"这个标准库函数叫什么""这里的语法怎么写"上,把本可以拿分的算法思路淹没掉。反过来,用你最熟的语言,你能把注意力全放在解法和沟通上——那才是面试真正给分的地方。所以最优策略往往很反直觉:选那门"无聊但你闭着眼都能写对"的语言。

两个关于"选语言"的常见误判。

其一,为了"显得厉害"而选一门不熟的语言(比如平时写 Python,面试硬上 C++)——结果在语法和内存细节上翻车,得不偿失。其二,以为某门语言"一定加分"——并不存在这种语言;面试官在乎的是能力而非语言标签。还有一个务实的坑:JavaScript、Ruby 在大公司面试可能受限,别默认能用,面试前先查清楚。

本周就动手做的一件事:用你打算带进面试的那门语言,把一个动态数组的 push 从零写出来——申请底层数组、追踪 size/capacity、满了就扩容。目标不是实现得多漂亮,而是确认一件事:你连语法(数组声明、扩容、边界判断)都不用查。哪一步卡住要翻文档,哪一步就是你面试当天会翻车的地方。

带走这一条:面试语言的唯一标准是"你能在白板上不查语法把它写对"。熟练度 > 语言本身的强弱;能力才是考点,语言只是载体。

五、自测题

Q1:对大公司的编程面试,通常固定接受的三种语言是哪三种?

C++、Java、Python。这是作者点明的、大公司面试基本固定的三个选择。此外 JavaScript 和 Ruby 也可能可以,但可能有限制,需要你事先向面试方查明,不要默认能用。核心不是"哪门最好",而是从被接受的语言里,挑一门你最熟、能不查语法快速写对的。

Q2:作者学习数据结构与算法时用到 C,主要理由是下面哪一个? (A) C 运行最快,能拿高分 (B) C 很底层,能直接操作指针与内存,让你看清数据结构与硬件的联系 (C) C 是面试唯一接受的语言

正确答案是 (B)。C 让你亲手处理指针、内存的分配与释放,这些细节在 Python/Java 这类高级语言里被隐藏了;学底层结构时"感受它们与硬件的联系"非常有益。(A) 把"学习价值"误当成"跑分"——面试不按运行速度给分;(C) 更是错的,面试固定接受的是 C++/Java/Python。注意区分:C 是作者的学习用语言,而不是他推荐的面试用语言(面试他偏爱 Python)。
