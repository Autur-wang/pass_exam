最短路:Dijkstra 与它的边界

BFS 能在无权图上求最短路,因为它把每条边都当作「1 步」。可现实里的边有权重——公里数、通行费、延迟。这时最少的「步数」不等于最短的「距离」。带非负权的单源最短路,标准答案是 Dijkstra 算法。这节课攻透它的贪心机制、为什么必须非负权,以及它和 BFS、Bellman-Ford、Floyd 之间的边界在哪。

先回忆两件事:BFS(第 0029 课)用队列逐层扩展、求无权最短路;优先队列(第 0022 课)能 O(log n) 地反复取出当前最小值。把这两样拼起来——用优先队列代替普通队列,永远优先扩展「当前距离最近」的顶点——你就几乎推导出了 Dijkstra。先想想:BFS 的普通队列为什么在带权图上会失效?

一、为什么 BFS 不够用了

无权图里,「离起点最近」就是「边数最少」,BFS 逐层扩展天然按这个顺序访问。但一旦边有权,一条「只走 1 条边但权重 100」的路,可能比「走 3 条边、权重各 1」的路更远。BFS 只数边数、不看权重,于是它先到达的顶点不再保证是最近的。我们需要一个按累计距离(而非边数)由近到远扩展的机制——把 BFS 的队列换成按距离排序的优先队列,就是 Dijkstra。

二、贪心机制:取最近、松弛、定终

Dijkstra 维护一个数组 dist[](起点到各点的当前已知最短距离,初始起点 0、其余 ∞),外加一个优先队列。循环做三件事:

  1. 取最近:从优先队列弹出当前 dist 最小、且还没定终的顶点 u。此刻 dist[u] 就是 u 的最终最短距离,永久确定,不再更新。
  2. 松弛(relax)邻边:对 u 的每个邻居 v,若 dist[u] + w(u,v) < dist[v],就更新 dist[v] 并把它(带新距离)推进优先队列。
  3. 重复,直到队列空(或目标点定终)。

三、为什么必须非负权

Dijkstra 的贪心赌的是一句话:「当前 dist 最小的未定终顶点,它的距离不可能再被后面的路径改小。」这句话只在所有边权非负时成立——因为再往后绕,只会加上 ≥0 的边,总距离只增不减。

可一旦有负权边,这个前提崩了:一个已经「定终」的顶点,可能通过一条后来才发现的负权边被绕出更短的路。Dijkstra 却因为「定终不再更新」而错过它,给出错误答案。所以负权最短路必须换 Bellman-Ford(它反复松弛 V−1 轮,不做「一锤定终」的贪心,还能检测负权环)。

四、关键定义

Dijkstra 算法
求带非负权图单源最短路的贪心算法:用优先队列每次取出当前距离最近的未定终顶点,松弛其邻边。避免「Dijkstra 能处理负权边」——不能,负权用 Bellman-Ford。
松弛(Relaxation)
对边 (u,v),若经 u 到 v 更近(dist[u]+w < dist[v])就更新 dist[v]。所有最短路算法的公共核心操作。
单源最短路(Single-Source Shortest Path)
固定一个起点,求它到所有其他顶点的最短距离。BFS(无权)、Dijkstra(非负权)、Bellman-Ford(可负权)都属此类;全源(每对顶点之间)用 Floyd-Warshall。

五、复杂度与边界对照

算法时间适用
BFSO(V+E)无权图(边权全为 1)
Dijkstra(二叉堆)O((V+E) log V)非负权、单源
Dijkstra(朴素数组)O(V²)稠密图反而可取
Bellman-FordO(V·E)可含负权、能检测负权环
Floyd-WarshallO(V³)全源、可负权(无负环)

把这张表读成一条决策链:无权 → BFS;非负权单源 → Dijkstra;有负权 → Bellman-Ford;要所有点对之间 → Floyd。BFS 是 Dijkstra 在「边权全为 1」时的退化特例——这也解释了为什么它俩长得那么像。

面试怎么考。最短路题的关键是先分类,再选算法:

  • 「网络延迟」「最小成本到达」「加权图从某点到各点」且权重非负 → Dijkstra。能顺口说出「优先队列 + 松弛,弹出即定终」就是内行。
  • 无权 / 权重全相等 → 别上 Dijkstra,直接 BFS 更简单更快(O(V+E))。面试官爱看你识别出这个简化。
  • 被追问「有负权怎么办」 → 答 Dijkstra 会失效(讲清贪心前提被破坏),改用 Bellman-Ford,它还能检测负权环。能把「为什么不能」讲清,比会背算法名更值钱。
  • 实现细节:用「懒删除」——优先队列里可能有同一顶点的多份过期记录,弹出时若发现取出的距离 > 当前 dist[u] 就跳过。

「Dijkstra 能处理负权边」——这是最经典的错。负权会破坏它「弹出即定终、不再更新」的贪心前提:一个已定终的点可能被后发现的负权边绕出更短路,而 Dijkstra 不再回头看它。负权请用 Bellman-Ford。这条几乎每轮图论面试都会被问到。

「出队即最终」这一点也常被误用。顶点一旦从优先队列弹出并定终,它的 dist 就不再改;但优先队列里可能还躺着它更早入队的过期副本,弹到时必须靠「距离比当前 dist 大就跳过」来忽略,否则会重复处理甚至出错。

另一个坑:别把 Dijkstra 和最小生成树(Prim)搞混。两者都用优先队列贪心,但 Dijkstra 比较的是「起点到 v 的累计距离」,Prim 比较的是「v 到已选集合的单条边权」——目标不同,松弛的量也不同。

照仓库大纲实现单源最短路(大纲「我会实现」里明确列了 Dijkstra):

dijkstra(graph, src):dist[] 初始化 ∞、src=0;优先队列存 (dist, 顶点);循环弹出最小、懒删除过期项、松弛邻边并把更新后的 (新dist, v) 入队;可选 prev[] 记录前驱以回溯完整路径。

带走这一条:非负权单源最短路用 Dijkstra(优先队列取最近 + 松弛,弹出即定终,O((V+E) log V));无权用 BFS(它是权全为 1 的特例);出现负权改用 Bellman-Ford——Dijkstra 处理不了负权。

六、自测题

Q1:一张有向图边权可能为负(比如「走这条路反而有补贴」)。你要求单源最短路。用 Dijkstra 行吗?为什么?

不行。Dijkstra 的正确性依赖「弹出即定终、之后不再更新」,而这只在边权非负时成立——非负保证再绕路只会更远。有负权时,一个已定终的顶点可能通过后来才被松弛到的负权边获得更短的路,Dijkstra 却不再回头看它,于是给出错误答案。此时应改用 Bellman-Ford(O(V·E),反复松弛 V−1 轮,还能检测负权环)。

Q2:一张无权连通图,求从某点到各点的最短距离。有人打算上 Dijkstra + 优先队列。有没有更好的选择?

直接用 BFS 就够了,而且更好。无权等价于「所有边权都是 1」,BFS 逐层扩展本身就按距离由近到远访问,O(V+E),没有优先队列的 log 开销。Dijkstra 在这种情形能得到正确答案,但杀鸡用牛刀,多了 log 因子。识别出「无权 → BFS」这个简化,是面试加分点。

Q3:用二叉堆实现的 Dijkstra,时间复杂度是?这个 log 因子从哪来?

O((V+E) log V)。每个顶点最多被定终弹出一次,每次松弛成功会往优先队列推一个更新项——总共至多 O(E) 次入队;堆的每次插入/弹出是 O(log V)。所以总时间 O((V+E) log V),log 来自二叉堆维护「当前最近顶点」的代价。补充:稠密图(E≈V²)上,朴素数组实现的 O(V²) 反而可能比 O(E log V)=O(V² log V) 更快。
