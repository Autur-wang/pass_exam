# Ch02: 位速查表(Bits Cheat Sheet)

**来源**: `cheat-sheets/bits-cheat-sheet.pdf`(1 页)

## Core Idea
一张表:给定 n 个比特位,能表示的无符号整数最大值、有符号整数的最小/最大值分别是多少。面试中判断"这个数据类型/字段会不会溢出"时直接查表。

## Key Concepts
- **无符号整数(unsigned)最大值** = 2ⁿ − 1(n 位全 1)。
- **有符号整数(signed, 补码表示)范围** = [−2ⁿ⁻¹, 2ⁿ⁻¹ − 1](符号位占 1 位,所以比无符号少一半)。
- 这张表本质是 2ⁿ 的幂表 + 上述两条规则的直接推论,不需要死记每一行,记住 n=8/16/32 三个常用值 + 推导公式即可。

## Key Takeaways
1. 8 位无符号最大值 255,有符号范围 [-128, 127]——这是 `byte`/`char` 类型溢出判断的基准。
2. 16 位对应无符号 65,535 / 有符号 [-32768, 32767]——常见于 `short` 类型和网络协议里的端口号字段(0–65535)。
3. 32 位对应无符号约 42.9 亿 / 有符号约 ±21.5 亿——这是 32 位整数溢出题(如"两数相加是否溢出")的标准参照值。
4. 通用公式:n 位无符号最大值 = 2ⁿ−1;n 位有符号范围 = [−2ⁿ⁻¹, 2ⁿ⁻¹−1]。记住公式比记完整表格更可靠。
