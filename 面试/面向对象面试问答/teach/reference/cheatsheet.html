面向对象(OOP)面试速查表

26 节的压缩精华,Python 为主。面试前十分钟扫一遍;每块对应课程一节,想深挖回去看对应微课。

四大支柱 0001–0005

  • 封装:捆绑 + 信息隐藏 + 受控访问(藏 how)。
  • 继承:is-a,子类得父类属性/行为;别为复用而继承。
  • 多态:共享接口统一对待;重写=运行时、重载=编译期。
  • 抽象:只给必要的(what);抽象类可有实现,接口是纯契约。

封装:Python 私有真相 0002

  • _x = 君子协定;__x = name mangling(改写为 _Cls__x),不是安全墙。
  • obj._Cls__x 照样能访问 → Python 无真 private。
  • 受控访问用 @property,别堆空 getter/setter。

继承类型 0003

  • 单 / 多 / 多层 / 层次 / 混合继承。
  • Python 用 super().__init__() 调父类;self = 别家的 this。
  • 坑:脆弱基类、强耦合 → 引出"组合优于继承"。

多态:重写 vs 重载 0004 / 0020

重写 override重载 overload
时机运行时编译期
如何子类换实现同名不同签名
Python随处可见不支持
  • Python 替代重载:默认参数 / *args / singledispatch;运算符重载靠 dunder(__add__)。

抽象类 vs 接口 0005 / 0021

  • 抽象类:可含默认实现 + 抽象方法;共享实现时用。
  • 接口:纯契约、无实现;多个不相关类遵守同一约定时用。
  • Python 无 interface:用 abc.ABC(名义、要继承)/ Protocol(结构、不用继承)/ 鸭子类型。

类的机制 0006–0009

  • is 比身份、== 比值(__eq__);判 None 用 is。
  • 构造:__new__ 造、__init__ 初始化;无构造重载 → @classmethod 命名构造器。
  • 清理别靠 __del__(时机不定)→ 用 with / context manager;C++ 靠 RAII。
  • @staticmethod(无 self/cls)/ @classmethod(cls)/ 实例方法(self);可变类变量会被所有实例共享。

关系:is-a / has-a 0010–0011

  • 继承 is-a · 组合 has-a(部分不可独立)· 聚合 has-a(部分可独立)· mixin can-do。
  • 组合 vs 聚合分水岭:部分能否脱离整体存在。
  • UML:关联实线 / 聚合空心菱形 / 组合实心菱形 / 继承空心三角。
  • 组合优于继承:除非明确 is-a。

内聚 & 耦合 0012

  • 口号:高内聚 + 低耦合(两个正交维度)。
  • 内聚(弱→强):偶然/逻辑/时间/过程/通信/顺序/功能。
  • 耦合(强→弱):内容/公共/控制/外部/印记/消息。

SOLID 0013–0015

  • SRP:一个类一个变化的理由。
  • OCP:对扩展开放、对修改关闭(多态代替 if-type)。
  • LSP:子类能替父类而不破坏正确性(反例:正方形 is-a 矩形)。
  • ISP:别逼类依赖用不到的方法(拆胖接口)。
  • DIP:都依赖抽象;DI = 从外部注入依赖(手段,非等于 DIP)。

设计模式(GoF 三类)0016–0018

  • 创建型:单例(Python 模块即单例)/ 工厂 / 建造者。
  • 结构型:适配器(改接口)/ 装饰器(加职责)/ 代理(控访问)。
  • 行为型:策略(换算法,Python 传函数即可)/ 观察者(一对多通知)/ 模板方法(骨架在父类)。
  • ⚠ Python @decorator 语法 ≠ GoF 装饰器模式。

多重继承 & MRO 0019

  • diamond:D(B,C),B/C 继承 A。
  • MRO(C3 线性化)定查找顺序,看 Cls.__mro__。
  • super() = MRO 里下一个,不是"父类";全用 super 时 A 只初始化一次。

相等、哈希、可变性 0022–0023

  • 重写 __eq__ 必配 __hash__,否则对象 unhashable。
  • 契约:a==b ⟹ hash(a)==hash(b);可哈希对象应不可变。
  • 传参 = 传对象引用;函数内改可变对象影响外部、重绑定不影响。
  • ⚠ 可变默认参数 def f(x, acc=[]) → 用 acc=None。

Pythonic 建类 0024

  • @dataclass 省样板;可变默认用 field(default_factory=list);frozen=True → 不可变 + 可哈希。
  • namedtuple 轻量只读记录;__slots__ 省内存/禁动态属性;Enum 具名常量。

范式对比 0025

  • 过程式:函数作用于(常全局的)数据,无继承/多态。
  • OOP:数据 + 行为捆进对象,封装 / 继承 / 多态。
  • FP:不可变 + 纯函数 + 高阶函数。
  • 范式是工具,无绝对高下;Python 多范式务实混用。

答题四步 + 白板法 0026

  • 答概念题:定义 → 为什么 → 最小代码 → 取舍/易错,再自抛追问。
  • 白板设计:澄清需求 → 找名词(类)/动词(方法) → 定关系(is-a/has-a) → 选模式 → 说取舍。
