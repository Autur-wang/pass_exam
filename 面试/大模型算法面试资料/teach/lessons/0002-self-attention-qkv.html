自注意力与 QKV:注意力到底在算什么

整个大模型的地基就一行公式:$\operatorname{softmax}(QK^\top/\sqrt{d_k})\,V$。这节课把它拆到你能空手写出来、并答得出面试官最爱追的三个「为什么」:QKV 从哪来、为什么用三套不同权重、为什么要除以 $\sqrt{d_k}$。

上节课(Transformer 整体结构)留了个扣子:RNN 处理序列要一步一步递推,离得远的词之间要走很多步才能「互相看到」,又慢又容易遗忘。先别往下看,试着回忆:如果想让序列里任意两个位置「一步」建立联系,你会怎么设计?

一、直觉:注意力就是「带权检索」

忘掉矩阵。注意力做的事,本质是一次加权求和:每个位置的新表示,是序列里所有位置的信息按「相关度」加权混合出来的。相关度越高,权重越大。

用查字典的比喻最好懂——三个角色 Q / K / V 各司其职:

Q(Query)
我要找什么
你带着的问题
K(Key)
每条信息的「标签」
书脊上的索引
V(Value)
每条信息的「内容」
书里真正的正文

流程就是:拿 Q 去和每个 K 比相似度(点积)→ 相似度经 softmax 变成一组和为 1 的权重 → 用这组权重去加权求和所有的 V。相似的键,它的值就被更多地读进来。

二、关键定义与公式

缩放点积注意力(Scaled Dot-Product Attention)
$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$
$Q\in\mathbb{R}^{n\times d_k}$、$K\in\mathbb{R}^{n\times d_k}$、$V\in\mathbb{R}^{n\times d_v}$;$n$ 是序列长度,$d_k$ 是每个头的维度。$QK^\top$ 得到 $n\times n$ 的注意力分数矩阵,行代表「谁在看」,列代表「看谁」。

三份角色都来自同一个输入,只是乘了三个可学习的权重矩阵:$Q=XW_Q,\;K=XW_K,\;V=XW_V$。「自注意力」的「自」就在这里——Q、K、V 全部源于同一段序列自己。

三、面试最爱的两个「为什么」

为什么 Q 和 K 要用不同的权重矩阵?

如果 $W_Q=W_K$,那么注意力分数 $QK^\top$ 就近似对称,而且一个词和自己的点积几乎总是最大——每个位置只会拼命关注自己,退化成没用的「自恋注意力」。用两套不同的投影,才能表达非对称的关系:「主语」该重点看「谓语」,但「谓语」未必同样看「主语」。语言里的依赖本就是有方向的。

为什么要除以 $\sqrt{d_k}$?

假设 $q,k$ 各维独立、均值 0、方差 1,那么点积 $q\cdot k=\sum_{i=1}^{d_k} q_i k_i$ 的方差会随维度线性放大:

$$\operatorname{Var}(q\cdot k)=d_k \quad\Rightarrow\quad \text{标准差} \approx \sqrt{d_k}$$

维度越大,点积绝对值越容易冲到很大。

点积一大,softmax 的输入就被推到饱和区——输出几乎变成 one-hot,梯度趋近于 0,训练几乎学不动。除以 $\sqrt{d_k}$ 把方差拉回 1 附近,softmax 停在梯度健康的区间。注意:除的是每个头的维度 $d_k$,不是 $d_{\text{model}}$。

把公式翻译成代码,自己敲一遍(注意 mask 加在 softmax 之前):

import torch, torch.nn.functional as F

def attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / d_k ** 0.5   # [n, n]
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    weights = F.softmax(scores, dim=-1)             # 每行和为 1
    return weights @ V                              # 加权求和

面试官会怎么问:

  • 「Q、K、V 分别是什么、从哪来?」——同一输入乘三套可学习权重;别答成「三个不同的输入」。
  • 「自注意力的时间/空间复杂度?」——$O(n^2 d)$,瓶颈在 $n\times n$ 的分数矩阵,这也是长上下文贵的根因(引出第 0008 课 FlashAttention)。
  • 「为什么除以 $\sqrt{d_k}$?不除会怎样?」——见上,考的是你懂不懂 softmax 饱和与梯度。
  • 「能不能用别的相似度代替点积?」——可以(加性注意力),但点积能用高度优化的矩阵乘,工程上更快。

易错点:

  • 缩放因子是 $\sqrt{d_k}$(单头维度),不是 $\sqrt{d_{\text{model}}}$。多头场景下 $d_k=d_{\text{model}}/h$。
  • 因果 mask 要在 softmax 之前把被遮位置设为 $-\infty$,让它 softmax 后权重为 0;在之后置 0 会破坏归一化。
  • 说「Q 和 K 可以共享权重」是错的——会导致注意力对称退化(见上)。

自测 1:缩放点积注意力里除以 $\sqrt{d_k}$,最主要是为了解决什么?

A. 把注意力权重归一化到 0~1 之间归一化是 softmax 干的事,不需要额外缩放。
B. 点积随维度增大而变大,推 softmax 进饱和区导致梯度消失 ✅正确。缩放把点积方差拉回 1 附近,让 softmax 停在梯度健康区间。
C. 加速矩阵乘法的计算缩放是逐元素除,不改变矩阵乘的计算量。
D. 防止模型过拟合与正则化无关。

自测 2:如果强行让 $W_Q=W_K$(Q、K 共享同一套权重),最可能出现什么?

A. 模型收敛更快、效果更好恰恰相反,表达能力被削弱。
B. 注意力分数矩阵趋于对称,每个位置过度关注自己,难以表达有方向的依赖 ✅正确。语言依赖是非对称的,共享权重会退化。
C. 完全不影响,只是省参数会显著影响表达能力,不是「无损省参」。
D. KV Cache 会失效与 KV Cache 无关(那是推理阶段的缓存,见第 0006 课)。

这节课的一手出处与深挖方向:

  • Attention Is All You Need(Vaswani et al., 2017)——缩放点积注意力与 Transformer 的原始论文,§3.2 就是本课公式。
  • 想弄清「$\sqrt{d_k}$ 从哪来」,顺着论文脚注读方差推导;本课的 $\operatorname{Var}(q\cdot k)=d_k$ 即出自此。
  • 下一步:多头把这套机制并行成 $h$ 份(第 0003 课),推理时怎么缓存 K、V(第 0006 课)。

一句话记忆:注意力 = 用 Q·K 的相似度做权重,对 V 加权求和;除以 $\sqrt{d_k}$ 是为了让 softmax 不饱和。
