这门课怎么用 + 前端面试地图

这个仓库里已经放好了一整套前端面试真材料——不是一份平铺的链接清单,而是 38 篇正文 + 40 道高频问答题的完整讲义。这节不讲任何具体的技术知识点,只回答一个更基础的问题:这些材料原本是按目录字母顺序排的,这门课把它们重新组织成什么顺序,以及你该怎么用。

开课前先想一想:如果现在有人问你「前端工程师面试和普通软件工程师面试,到底有什么不一样」,你能不能说出至少一点具体的差异?先给自己一个诚实的答案——这决定了接下来 46 节课,哪几节对你是真正的新知识,哪几节可以先跳过。

一、这个仓库是什么、材料从哪来

这个仓库是 GreatFrontEnd 维护的开源项目《Front End Interview Handbook》的中文翻译版本。README 里说得很直接:frontendinterviewhandbook.com 是原始网站,这份仓库把「前端面试的各种形式」「前端系统设计面试」「前端 trivia 问答」「前端编码题」几大块内容,连同简体中文翻译,一起放进了本地目录。

这一点和同一个 面试/ 目录下的姊妹课程不太一样——比如《工程领导力资源》那门课的源材料只是一份 200+ 条的资源链接清单,而这个仓库里躺着的是可以直接读的完整讲义正文。这意味着这门课的每一节,都应该先去读对应的真实源文件,而不是靠"前端面试大概考什么"的通用印象去写。

本地目录里实际存在(不是 README 里提到但没克隆下来的)五块内容,规模都用真实文件数核实过:

三、这门课怎么组织:7 个部分,46 节课

原始材料是按目录字母顺序平铺的,但备考是有先后依赖关系的——比如你需要先知道"前端面试分几道关卡",才能判断自己该优先补哪一关。这门课把上面五块内容,重新编排成一条从"面试地图"到"简历与行为面试收尾"的顺序:

Part 1-2地图 + 编码基础面试考什么、JS/算法/编码面试怎么区分
Part 3-4Trivia + UI 编程HTML/CSS/浏览器高频问答、组件 API 设计
Part 5-7系统设计 + React + 收尾RADIO 框架、React 专题、简历与行为面试

每节课只攻一个窄主题,10~15 分钟能读完;每节都指向对应源文件里真实存在的参考链接,不会凭空编一个"看起来应该有"的链接。

四、关键定义

Front End Interview Handbook
GreatFrontEnd 维护的开源前端面试手册,本仓库是其中文翻译版本的本地拷贝。避免把它和 GreatFrontEnd 的付费刷题平台混为一谈——手册是免费的讲义,平台是另外的付费实战产品。
这门课(teach/)与仓库本体的关系
仓库本体(前端系统设计/ 等五个目录)是原始一手材料,按目录字母顺序平铺;teach/ 是在此基础上重新编排出的一条学习顺序,每节课都能追溯到具体的源文件。避免把这门课当成独立于仓库本体的新内容——它没有编造任何仓库里不存在的知识点。

现实中怎么用。不需要严格从 0001 按顺序啃到 0046。如果你已经对 CSS/HTML 很熟,可以跳过 Part 3(HTML/CSS/浏览器高频问答),直接从 Part 5(前端系统设计)或 Part 6(React 专题)开始;如果只剩几天就要面试,行为面试(Part 7)的性价比往往比再刷十道 CSS trivia 题更高。判断标准很简单:哪一关你现在最没底,就先学哪一部分。

一个容易踩的误区:把"读完这 46 节课"当成终点。这门课负责讲清楚"为什么这么问、该往哪个方向想",但前端面试真正的手感,来自动手写代码——具体的实战练习题在 GreatFrontEnd 平台本身(见文末链接),不在这门课里重复造一遍。读完某节课觉得"懂了",和面试现场能不能在 15 分钟内写出来,是两件不同的事,后者需要真正动手。

本周就动手做的一件事:花 5 分钟,对着上面的 7 个部分表格,诚实标出"这一关我有底"还是"这一关我心里没数"。这份自评就是你接下来该优先学哪几节的依据,比按数字顺序死磕更有效率。

带走这一条:这个仓库里是可以直接读的完整讲义,不是一份链接清单;这门课把它重新组织成 7 个部分、46 节课,但不需要按顺序全学——先诊断自己卡在哪一关,再挑对应部分深挖。

五、自测题

Q1:关于这个仓库和这门课的关系,下面哪个说法最准确? (A) 仓库本体只是一份链接清单,实际内容全靠这门课凭经验编写 (B) 仓库本体自带可直接阅读的完整讲义正文,这门课只是把它们重新组织成一条学习顺序 (C) 这门课和仓库本体的内容互相独立,没有关系

正确答案是 (B)。仓库自带 38 篇正文 + 40 道问答题的完整讲义,这门课的每一节都追溯到具体的源文件。(A) 弄反了信息来源;(C) 忽略了这门课正是基于仓库本体重新编排出来的。

Q2:如果只剩几天就要面试,且已经对 CSS/HTML 很熟,比较合理的学习策略是下面哪一个? (A) 仍然严格从 0001 按顺序学到 0046,一节不落 (B) 跳过已经熟悉的部分,优先补自己心里没数的部分,比如系统设计或行为面试 (C) 直接跳到最后一节,从后往前倒着学

正确答案是 (B)。这门课明确建议先自评"哪一关没底",再针对性深挖,而不是不管基础如何都从头学到尾。(A) 忽略了已经掌握的内容没必要重学;(C) 只是把"按顺序"倒过来,同样没有针对薄弱环节。
