# NOTES.md

工作笔记与偏好,供接手会话快速对齐。截至 2026-07-17,本课程刚建成,尚未有真实授课会话——以下是建课阶段定下的规则,不是从用户反馈里总结出来的。

## 真实源与引用纪律

- 本课程的正文内容**直接来自仓库本体**——`前端系统设计/`、`综合面试手册/`、`行为面试手册/`、`React面试手册/`、`quiz题库/` 下的 `zh-CN.mdx`(缺失时用 `en-US.mdx`)。这和姊妹课程(编程面试大全、工程领导力资源)只有一份扁平资源清单不同:这里有全文可读的真实讲义,讲课时应该**读源文件再写**,不是凭对"前端面试"这个话题的通用印象编。
- 每节课引用的外部链接,只能是该课对应源 mdx 文件里**已经出现过**的链接(或 `README.md` 里出现过的链接,用于课程整体介绍类的课)。不要因为一个链接"看起来很像会出现在这里"就加进去——姊妹课程「工程领导力资源」建课时就踩过这个坑:把姊妹课程记忆里一个真实存在的资源链接当成本课源材料编了进去,详见 memory `workflow-resume-replays-writes` 同批建课记录。
- 两篇没有官方中文翻译的源文件(`行为面试手册/resume-walkthrough`、`行为面试手册/adaptability-flexibility`,只有 `en-US.mdx`):对应课程直接读英文理解、用中文讲授,但**不能**假装存在一篇官方中文原文并给它编一个链接。
- 「唯一/总是/永远/绝对」等绝对措辞,只能用在否定句或场景描写里,不能用来做断言——这条纪律同上一门课(工程领导力资源)一致。

## 房屋风格

复用 `编程面试大全/teach/` 与 `工程领导力资源/teach/` 验证过的结构化 CSS 骨架与七件套教学装置(`.recall/.keydef/.apply/.pitfall/.practice/.good/.quiz`),换一套新配色(陶土红/钢青蓝/松绿/琥珀)区分本课程。图示库沿用 `.trio/.pipeline/.flow/.bars/.svg-wrap`,新增一个本课专属的 `.codecompare`(两段代码并排对照,标好 good/bad),因为本课内容比姊妹课程多得多的真实代码示例(React 状态/表单/Hooks)。`.codecompare` 是可选装置,不是每课必须用。金标准母版是 `lessons/0001-how-to-use-this-course.html`,手写并浏览器截图验收过。

## 规模

46 课,是目前 `pass_exam` 仓库里同类 `teach/` 课程中规模最大的一门——因为源材料本身就是一份约 38 篇正文 + 40 道问答题的完整手册,不是扁平清单,拆分密度按各源文件真实篇幅(行数)决定,不是拍脑袋定的整数。`React面试手册/react-forms`(近 800 行)拆成 3 课,是全书单份材料拆分最多的一处。
