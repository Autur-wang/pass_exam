# NOTES · 教学偏好与工作区说明

## 这门课是什么
「生成式 AI / AI 工程师面试冲刺」精读课。范围与难度由用户拍板(2026-07-17):
- **主线 = 面试冲刺版**:以两大真题库为骨——`60_gen_ai_questions.md`(62 题,基础/理论)+ `roles/ai-engineer/questions.md`(145 题,应用),**AI 工程师岗位为主骨**。每节课 = 一簇高频真题,深答到面试级。
- **面试视角 = 每课都落到面试**:保留 `🎯面试怎么考` + `⚠面试易错点` 装置,并从题库提炼该主题的高频追问链,直接给面试级答法。
- 载体 = 可离线打开的自包含 HTML 微课,本地 KaTeX 渲染数学(源偏应用,公式点到为止)。

## 教学法(遵仓库教学人设)
- **交互式授课**,不一次灌满:复述→补缺→AskUserQuestion 出题校验;先确认掌握再推进。
- 每节体例:`🔁先回忆 → 直觉/原理 → 关键定义 → 🎯面试怎么考 → ⚠面试易错点 →(可选)⌨️自己写一遍 → 自测题(details 收答案)→ 📄延伸 → 上下课导航`。
- 出选择题打乱正确项位置;提交前不公布答案。

## 内容纪律(反幻觉)
- **只答源里有的题**:题目锚定两大真题库真实存在的问题,不编造面试题。
- **不编数字**:benchmark、加速比、显存倍数、版本参数、具体安全统计——只用源材料/一手论文里真实出现的;安全课引用 `securing_agentic_ai_systems.md` 的具体数字前须回读原文。
- **绝对措辞是幻觉指纹**:「唯一/一定/所有」类断言必给反例(见 gotcha 装置)。
- 源里没有的就说没有:扩散数学、函数调用线格式、多模态最新细节——点到为止,别硬凑。

## 房屋风格(与姊妹课共享装置,独立内容)
- 全课 link 一份 `assets/style.css` + 本地 `assets/katex/`。装置类名见 style.css:`.recall/.keydef/.interview/.gotcha/.implement/.good/.quiz/.trio/.pipeline/.flow/.paper/.lesson-nav`。
- **KaTeX 的 `<` 陷阱**:HTML 源码里数学区的 `<`/`>` 必须写 `&lt;`/`&gt;`,否则被浏览器当标签吃掉致公式不渲染且不报错。核验数学要三层并查:console 错误 / `.katex-error` / 渲染后残留 `$`。
- 编号 `NNNN-dash-case-topic.html` 递增;prev/next 用**精确文件名**(避免猜 slug 造死链)。
