速查表 · 生成式 AI / AI 工程师面试冲刺

面试前 10 分钟扫一遍。每块对应课程一个主题;要展开看对应微课。

① 注意力(0002-0005)

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$
  • Q/K/V = 同一输入乘三套可学习权重;「自」= 全来自同一序列。
  • 除 $\sqrt{d_k}$:防点积随维度增大把 softmax 推入饱和区 → 梯度消失。除的是单头 $d_k=d_{\text{model}}/h$。
  • Q、K 用不同权重:否则注意力对称退化、只盯自己。
  • 多头 = 多视角并行、总计算量同量级(非更省)。复杂度 $O(n^2 d)$ → 长上下文贵的根因。
  • 长上下文救法:FlashAttention、MQA/GQA、RoPE/ALiBi、位置插值、稀疏注意力。

② 模型类型 & 解码(0004-0005)

  • base=只预测下一 token / instruct=听指令(产品默认)/ reasoning=答前花 test-time compute。
  • GPT=解码器·自回归·擅生成;BERT=编码器·双向·MLM+NSP·擅理解。
  • temperature 缩放分布(抽取/工具调用用低温);top-p 只在累计概率 p 内采样。只调一个。
  • KV cache → prefill(算力密集,主导 TTFT)+ decode(访存密集,逐 token 便宜)。
  • 相同调用不保证相同输出(浮点非结合、MoE 路由、静默更新)→ pin 版本 + 回归 eval。

③ Embedding & 向量检索(0006-0007)

  • embedding=稠密低维、语义近则向量近。triplet loss:$\max(0,\,d(a,p)-d(a,n)+\text{margin})$。
  • 索引:flat 精确不 scale · HNSW 图·低延迟高召回·内存大 · IVF 聚类·省内存·需调参。
  • ANN 家族:LSH / 树 / 图(HNSW)。量化 float32→int8 省内存。
  • 选 embedding 模型:在自己数据上评检索,别信 leaderboard。

④ Prompting & 上下文工程(0008-0010)

  • zero-shot 默认 → few-shot 定格式(每例都是每次的成本)→ CoT(推理模型别再强加)。
  • 结构化输出:provider schema + 代码校验 + 失败重试,别用正则抠散文。
  • context rot:输入越长准确率越降(窗口没满也降)。lost-in-the-middle:首尾利用最好。
  • 缩上下文三法:clear(裁剪·无损)/ compact(摘要·有损)/ offload(存外部)。
  • 可信指令与不可信数据(检索/工具/网页)用角色分离 → 防注入第一道防线。

⑤ 微调 & 对齐(0011-0012)

  • 四选一:prompting(可指定行为)→ RAG(新鲜/私有/需引用知识)→ 微调(稳定行为/格式,非易变事实)→ agent(确需多步动态动作)。
  • PEFT:LoRA($\Delta W=BA$ 低秩)/ QLoRA(量化基座+LoRA)/ Adapter / Prompt Tuning。
  • 对齐:RLHF(奖励模型+PPO,经典三段)/ DPO(去奖励模型直接优化)/ GRPO(组内相对+可验证奖励)。
  • 灾难性遗忘 → gradual unfreezing、分层差异学习率、领域继续预训练。

  • 检索:dense(语义)/ sparse(BM25 词面)/ hybrid(RRF 融合,生产最优)。reranker(cross-encoder)= 多召回后精排。
  • 进阶:contextual retrieval(块前置定位描述)/ late chunking(整篇编码再池化)/ HyDE(先草拟假答案再嵌)/ metadata 过滤 / query routing。
  • RAG triad:context relevance(检索)· faithfulness(生成忠实)· answer relevance(答到点)→ 定位失败在哪环。
  • 覆盖不到 → 优雅拒答(阈值+"只据上下文答"),别幻觉。企业级:权限过滤+增量索引先设计。
  • 带检索反更差:坏检索比不检索还糟 → 单独评检索阶段。百万上下文≠RAG 过时(仍需选切片/权限/引用)。

⑦ Agents(0018-0021)

  • agent = model + harness(工具+记忆+循环+门控)。能用 workflow(固定步骤)就别用 agent。
  • ReAct(Yao et al.):思考→行动→观察→循环。function calling:模型发结构化请求、你的代码执行喂回。
  • tool design = token design:少而好、search-first、错误可行动、告诉它何时别调。
  • MCP=一次接入处处复用(纵向连工具);A2A=agent 间协作(横向)。
  • 记忆:短期=当前上下文 / 长期=外部存储按需检索。orchestrator-worker:子 agent 传短结构化结果非原始轨迹。
  • 误差累积:$0.95^{20}\approx36\%$ → 测端到端 & pass^k(k 次全成),不看平均。

⑧ 推理模型(0022)

  • 答前花 test-time compute(隐藏思维链)→ 数学/代码/多步更强,更慢更贵。
  • 难题用推理模型、常规用标准模型 → 路由:便宜走常路、难例升级。
  • thinking budget 按难度调;过度思考(inverse scaling):某些题更多推理反更差。
  • 可见思维链未必忠于真实计算 → 别当审计轨迹。self-consistency=多路径取多数。

⑨ 评估(0023-0024)

  • LLM-as-judge 偏差:位置 / 冗长 / 自我偏好 / 不一致 → 随机顺序 + 对人工校准(目标 85~90% 一致)再门禁。
  • pointwise(绝对分,CI 门禁)vs pairwise(比优劣,选型)。
  • error analysis=读失败、打标、聚类 → 最高杠杆,直指该修哪。
  • offline(固定集·门禁发布)+ online(真实流量·抓 drift)都要。eval-driven CI:回归阻断合并。
  • 公榜:污染(泄进训练)+ 饱和(齐聚天花板)→ 信自己数据的私有 eval。

⑩ 成本延迟 & 部署(0025-0026)

  • 三角:latency / throughput / cost 不可兼得,先定绑定约束。
  • TTFT(prefill·随输入长)vs inter-token(decode·随模型)→ 修法不同。
  • 缓存:prompt/KV(共享前缀折扣)· 语义(相似即返回,免调用但有近似命中风险)。稳定部分放前。
  • 投机解码(小模型草稿+大模型校验)· 连续批处理(token 级调度提吞吐)· model routing。
  • fallback:超时+退避+断路器+降级;成本按功能/租户归因监控。

⑪ 幻觉 & 安全(0027-0028)

  • 幻觉不可根除,只能 reduce(grounding)+ detect(faithfulness/引用核验)+ contain(显来源/拒答/转人)。
  • 检测:Seq-Logprob · SelfCheckGPT · G-EVAL · NLI 蕴含。perplexity 局限:忽略连贯/事实。
  • prompt injection:direct(用户)vs indirect(藏在检索/工具/网页,更糟)。jailbreak≠injection(前者攻模型护栏,后者攻你的应用)。
  • tool poisoning(恶意 MCP 元数据)· excessive agency(权限超需)→ 最小权限、人审高危、爆炸半径。
  • 护栏 = 模型外确定性校验(输入+输出)。OWASP LLM Top 10 当威胁建模检查表。

⑫ 多模态 & 系统设计(0029-0031)

  • VLM:图像→视觉 token→投影到文本嵌入空间→一起注意力。图像耗大量 token。
  • MM-LLM 五部件:编码器→输入投影→LLM→输出投影→生成器。CLIP=对比对齐 / DALL-E=文生图。
  • 系统设计骨架:需求(准确/延迟/成本/合规)→ 检索 grounding + 最小权限工具 + 低置信转人 → 评估+可观测+护栏 → fallback 灰度 + 人在环。每步点取舍。
  • 工程判断:何时别用 LLM(确定性规则更优)· build vs buy · 每次交互成本 · prototype→prod 鸿沟在评估与可靠性。

一句话:面试冲刺 = 懂原理 + 讲清为什么 + 落到工程取舍 + 答得住追问。回门户逐节展开:index.html。
