# 面试/ 板块导航

本目录是仓库里**当前最活跃**的板块，聚合面试备考的多门精读课与参考资料。子目录按性质分为四类，取用前先看清它属于哪一类：

## 一、建成的 teach 精读课（可直接开讲 / 复习）

每门课都是同构的 `teach/` 脚手架（`MISSION.md` / `GLOSSARY.md` / `RESOURCES.md` / `learning-records/` / `lessons/`），微课在各自 `teach/lessons/` 下。

| 课程 | 微课数 | 主题 |
|---|---|---|
| `编程面试大全/` | 52 | 数据结构与算法 + 系统设计 |
| `前端面试知识库/` | 46 | 前端 trivia / UI 编程 / 前端系统设计 / React / 行为面试 |
| `生成式AI学习指南/` | 31 | 生成式 AI / AI 工程师面试冲刺 |
| `大模型算法面试资料/` | 31 | Transformer → 微调 → RAG → Agent → RL → 推理工程（含公司面经） |
| `工程领导力资源/` | 30 | IC / 管理路线 → Staff+ → CTO |
| `面向对象面试问答/` | 26 | OOP 四支柱 → SOLID → 设计模式 |
| `LightRAG知识图谱RAG/` | 37 | 知识图谱 RAG（**注**：同目录还叠着一份克隆的 LightRAG 完整代码库 + 中文知识分支笔记） |

## 二、空脚手架（尚未建课）

| 目录 | 内容 |
|---|---|
