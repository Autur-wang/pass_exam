## L1 · 课件要「图文并茂 + 多举实例对比」（2026-07-06，多媒体 0004）
- **反馈**：用户看 0004 颜色科学，指出"不够图文并茂、没有举例子做比较讲解"。
- **根因**：微课偏文字，抽象概念（颜色空间）没有配图，缺少钉在具体实例上的对比。
- **规则**：
  1. 空间/颜色/波形/几何/流程类概念 → 必须配**内联 SVG / CSS 渐变**现画的图（本地 file:// 打开，可放心用 `mix-blend-mode`、`conic-gradient`、SVG path）。
  2. 抽象概念 → 钉到一个**具体实例**（如"同一个橙色·五套坐标系"），并给**并排对比图**。
  3. 改完 → **无头 Chrome 截图回看**验证渲染，别只读代码就说好。
- **已固化**：写入 `多媒体/teach/NOTES.md` 的「图文并茂规范」，样板为 0004。后续所有微课与改版按此办理。
