I.单选精讲 · 10 题(每题 2 分,共 20 分)

单选 1多媒体应用 · L01

文本处理(字处理)软件的主要用途是什么?

答案文字的录入、编辑与排版(如 Word)。
精讲本章属「多媒体应用软件」概念题。字处理面向文字;图像/音频/视频各有专用工具。区分「应用类型」与「媒体类型」即可。
单选 2多媒体概念 · 第一章

下列哪一项不属于多媒体的基本特征?

答案不可压缩性。
精讲多媒体四大基本特征 = 多样性、集成性、交互性、实时性。多媒体数据恰恰高度可压缩(否则视频没法传),「不可压缩」是反的。
单选 3音频量化/传输 · L05

压缩音频时,主要需要考虑哪些因素?

答案采样率、量化位数、声道数(并可利用听觉掩蔽做感知压缩)。
精讲音频数据量 = 采样率 × 量化 bit × 声道数;质量与体积都由这三项决定。屏幕分辨率/帧率是视频/图像的量,与音频无关。
单选 4无损 vs 有损 · L06

下列哪一项是音频的无损编码?

答案FLAC(及 ALAC)。
精讲MP3 / AAC / Ogg Vorbis 都是有损感知编码;FLAC 用熵编码(游程/Huffman 类)可逐比特还原。判断口诀:「能完全复原」才是无损。
单选 5数据量单位 · L04

求一段视频的数据量,并区分 MB 与 Mb。

答案关键:1 Byte = 8 bit,MB(大写 B=字节)与 Mb(小写 b=比特)差 8 倍。
精讲例:900 MB × 8 = 7200 Mb = 7.2 Gb。视频数据量 = 宽×高×fps×时长×每像素字节。真题第 5 题的陷阱就在 b/B 混淆——最后一步换算务必看清大小写。
单选 6均匀量化 · L07

均匀标量量化中,被划分为等距区间的是?

答案输入信号的动态范围。
精讲均匀量化把「输入的取值范围」切成等宽区间(步长 Δ 恒定),每个区间映到一个重建电平。被等分的是输入幅度轴,不是误差、不是时间轴。
单选 7音频数字化 · L05

数字音频的获取与处理,正确顺序是?

答案采样 → 量化 → 编码。
精讲先采样(时间离散化,满足奈奎斯特 fs≥2fmax)→ 再量化(幅度离散化,如 16 bit)→ 最后编码(PCM/熵编码)。顺序不能颠倒:没采样谈不上量化。
单选 8VQ vs SQ · L07

向量量化(VQ)与标量量化(SQ)的主要区别在于?

答案VQ 把多个样本组成矢量整体查码本;SQ 逐样本独立量化。
精讲SQ 一次量化一个数;VQ 把 k 个样本拼成矢量,在码本里找最近码字,利用了样本间相关性,率失真更优,代价是要设计/存储码本。
单选 9JPEG2000 · L08

JPEG2000 相比 JPEG 的主要优势来自?

答案采用离散小波变换(DWT)替代 8×8 分块 DCT。
精讲DWT 对整幅图做多分辨率分析,没有块效应,天然支持渐进传输与感兴趣区(ROI)编码。这是「为什么小波比分块 DCT 好」的标准答案。
单选 10运动估计 · L09

2D 对数搜索(2D-log search)主要应用在何处?

答案视频运动估计中快速搜索最优运动矢量(MV)。
精讲它用「对数级递减的步长」逼近 MAD 最小点,避免全搜索的巨大计算量。属于块匹配运动估计的快速搜索策略。

II.简答范文 · 2 题(每题 5 分,共 10 分)

简答 1 · 高频L07 有损压缩

简述率失真理论(rate-distortion theory),并说明率失真曲线 R(D) 上点的含义。

参考范文① R(D) 的定义:在允许失真不超过 D 的前提下,编码所需的最小比特率;D(R) 是它的反函数。
② 曲线形状:R(D) 单调递减、下凸——给的码率越高,可达到的失真越小;码率越低失真越大。
③ 两个端点:D=0(无失真)时 R = 信源熵 H,对应无损压缩的极限;D 增大则 R 下降,落在曲线上的点对应有损压缩。
④ 意义:曲线是理论下界,任何实际编码器只能工作在曲线上方或曲线上,越贴近越优。
答题提示:务必画出 R-D 坐标图(横轴 D、纵轴 R,下凸曲线),并标注 D=0→R=H 这个端点。
简答 2 · 中频L11 CBIR

图像检索中,如何计算图像间内容的相关性?

参考范文① 提取特征:全局(颜色直方图、纹理、形状)或局部(SIFT/SURF 关键点描述子),把每幅图表示为特征向量。
② 定义距离/相似度:用 L1(曼哈顿)、L2(欧氏)、余弦相似度、直方图相交等度量两向量的接近程度,距离越小 → 内容越相关。
③ 距离须满足四性质:非负、同一(d(x,x)=0)、对称(d(x,y)=d(y,x))、三角不等式。
④ 语义鸿沟:低层特征相近未必语义相关,需靠标注的相关集(ground truth)评判;相关性结果最终用于计算 Precision/Recall/AP/mAP。

III.计算精讲 · 4 题(每题 15 分,共 60 分)· 重心

真题的分数重心。四种题型各一道,把分步解法背到条件反射。想再练可上 模拟卷 A / 模拟卷 B(同结构、换数字)。

计算 1 · JPEG:Zig-zag → DC-DPCM / AC-RLC → HuffmanL08 JPEG

给定某 8×8 亮度块量化后系数(只写非零,其余全 0),前一块 DC=12。要求:Zig-zag 展开 → DC 做 DPCM、AC 做游程(run,level) → 再对 AC 做 Huffman 编码。

行,列从 0 计:
(0,0)=16   (0,1)=0   (0,2)=-2
(1,0)=-3   (1,1)=-1
(2,1)=-1
其余全部为 0

真题为回忆卷,此处用同型代表数据(与模拟卷 A 一致,已代码验证)。

  1. Zig-zag 展开成一维。沿"之"字序从左上扫到右下:16, 0, −3, 0, −1, −2, 0, 0, −1, 0, …(其余全 0)。目的是把低频集中在前、把大量高频 0 赶到尾部,利于游程。
  2. DC 用 DPCM。只对直流分量编前后块差值:本块 DC − 前块 DC = 16 − 12 = 4。差分值 4 的类别(size)=3(需 3 bit 表示幅值),码流 = Huffman(DC,size=3) + 幅值 3 bit。
  3. AC 用游程(run, level)。去掉 DC 后的 AC 串 0,−3,0,−1,−2,0,0,−1,0,…,按(前导 0 个数, 非零值)配对:
    (1,−3) (1,−1) (0,−2) (2,−1) EOB。末尾全 0 用 EOB 收束。
  4. 对每个 AC 对做 Huffman。JPEG 把每个 AC 写成 (RUN, SIZE) 查 Huffman 表得前缀码,后面紧跟 SIZE 位幅值码(负数取补):
    (run, level)run/size幅值码
    (1,−3)1/200
    (1,−1)1/10
    (0,−2)0/201
    (2,−1)2/10
    EOB0/0—
    最终码流 = Huffman(run,size) 前缀码 + 幅值码 依次拼接。(考试给标准 Huffman 表时代入即可;不给表则写到"(run,size)+幅值"这一步。)
结论:Zig-zag 16,0,−3,0,−1,−2,0,0,−1;DC-DPCM =4;AC-RLC (1,−3)(1,−1)(0,−2)(2,−1)EOB。五步链条:分块→DCT→量化→Zig-zag+DPCM/RLC→熵编码,量化是唯一有损步。
计算 2 · 视频压缩:最优 MV / MAD + 2D 对数搜索L09 运动补偿

当前帧一个 4×4 宏块 C,在参考帧 10×10 搜索区 R 中找最优运动矢量。约定 MV=(dx,dy)=向右 dx、向下 dy;MV=(0,0) 时 C 对齐 R 的 rows3–6、cols3–6;MAD=(1/N²)Σ|C−R对应块|,N=4,搜索范围 ±3。求最优 MV 及 MAD,并用 2D 对数搜索求解。

                   r5: 25 22 21 22 25 30

同型代表数据(模拟卷 A,已代码验证);最优点处 C 与 R 子块完全重合。

  1. 理解 MAD。把 C 平移 (dx,dy) 后与 R 对应 4×4 子块逐像素求绝对差之和,再除以 16。MAD 越小越匹配,=0 表示完全重合。
  2. 2D 对数搜索 · 第一轮(中心 (0,0),步长 step=2)。取"中心 + 上下左右"5 点算 MAD:
    MV(dx,dy)(0,0)(+2,0)(−2,0)(0,+2)(0,−2)
    MAD4.528.57.3754.25
    最小在 MV(+2,0),MAD=2 → 作为下一轮中心。
  3. 第二轮(中心 (+2,0),步长减半 step=1)。
    MV(dx,dy)(+2,0)(+3,0)(+1,0)(+2,+1)(+2,−1)

    最小在 MV(+2,−1),MAD=0 → 收敛。

结论:最优 MV=(+2,−1),MAD=0(C 与 R 的 rows2–5、cols5–8 子块完全重合)。易错:MAD 用绝对值不是平方(那是 MSE);2D 对数搜索每轮步长减半。
计算 3 · 算术编码:编码 + 解码L06 无损压缩

信源 4 符号,概率 P(A)=0.4, P(B)=0.2, P(C)=0.3, P($)=0.1($ 为终止符),累加区间 A[0,0.4) B[0.4,0.6) C[0.6,0.9) $[0.9,1)。对 B A C $ 编码,给出最终区间与最短二进制码字;再用同表解码验证。

同型代表数据(模拟卷 A,已用分数精确验证)。老师标注:编码为重点,解码了解即可。

  1. 逐符号缩窄区间。每读一个符号:new_low=low+range×R_low,new_high=low+range×R_high(range=high−low)。
    读入lowhigh
    B0.40.6
    A0.40.48
    C0.4480.472
    $0.46960.472
    最终区间 [0.4696, 0.472)。
  2. 取区间内最短二进制小数作码字。在 [0.4696,0.472) 内找分母为 2 的幂的最短小数:241/512 = 0.470703…,即 0.011110001(9 位)。
  3. 解码(反向定位)。取码值 v=0.470703,逐步判断落在哪个符号区间、再归一化:
    ① v∈[0.4,0.6)→B;② (v−0.4)/0.2=0.354∈[0,0.4)→A;③ (v−0.4)/0.08=0.884∈[0.6,0.9)→C;④ (v−0.448)/0.024=0.946∈[0.9,1)→$,停。
结论:码字 241/512 = 0.470703(0.011110001);解码还原 B A C $ ✓。要点:编码是"区间不断缩小",码字取区间内表示最短者;$ 是停止信号。
计算 4 · 图像检索指标:Precision / Recall / AP / mAPL12 检索评价

两个查询的返回排序(✔=相关,✘=不相关)与相关总数如下。求 Q1 各位置 Precision@k / Recall@k;求 AP(Q1)、AP(Q2);求 mAP。AP=命中位置 Precision 之和 ÷ 相关总数。

Q1(相关总数=5):  ✔ ✘ ✔ ✔ ✘ ✔
Q2(相关总数=4):  ✘ ✔ ✔ ✘ ✔ ✘

同型代表数据(模拟卷 A,已代码验证)。

  1. Q1 逐位置扫。维护"累计命中数",P@k=命中/k,R@k=命中/5:
    rank命中P@kR@k
    1✔1.0000.20
    2✘0.5000.20
    3✔0.6670.40
    4✔0.7500.60
    5✘0.6000.60
    6✔0.6670.80
  2. AP(Q1)=只把命中行的 P 相加 ÷ 相关总数。命中在 rank 1,3,4,6:(1.000+0.667+0.750+0.667)/5 = 3.0833/5 = 0.6167。
  3. AP(Q2)同法。Q2 命中在 rank 2,3,5,P=0.500,0.667,0.600:(0.500+0.667+0.600)/4 = 1.7667/4 = 0.4417。
  4. mAP=各查询 AP 的均值。(0.6167+0.4417)/2 = 0.5292。
结论:AP(Q1)=0.6167、AP(Q2)=0.4417、mAP=0.5292。易错:AP 分母是相关总数(不是返回数);只累加"命中位置"的 Precision;漏检的相关项按 P=0 计入,会拉低 AP。

IV.综合论述 · 1 题(10 分)

综合论述 · 高频L04 + L08 · YCbCr 与色度二次采样

围绕 YCbCr 与色度二次采样:(1) 4:4:4 / 4:2:2 / 4:2:0 哪种传输效率最高?画示意图并定量说明;(2) 4:2:0 如何发送数据、如何还原为 RGB?(3) 前 4 个像素 Cb/Cr 全保留,Y 只留 Y₀、Y₁(已知 Y₀=80、Y₁=120,且 Y₄=200),用线性插值重构 Y₂、Y₃。

参考范文 (1) 效率最高 = 4:2:0。每 2×2=4 像素:4:4:4 存 4Y+4Cb+4Cr=12 采样(3 B/px);4:2:2 存 4Y+2Cb+2Cr=8(2 B/px);4:2:0 存 4Y+1Cb+1Cr=6(1.5 B/px)。相对 4:4:4,4:2:0 只占 50%,压缩最狠。依据心理视觉冗余:人眼对亮度 Y 敏感、对色度 Cb/Cr 不敏感,大幅降采样色度几乎无感损。 
4:4:4        4:2:2        4:2:0
Y Y          Y Y          Y Y
Y Y          Y Y          Y Y
每点都有色度  每行取一半色度  每 2×2 共享一组色度
(2) 发送与还原。Y 逐像素全采样发送;Cb、Cr 每 2×2 块只发一个(左上或取平均)。还原 RGB:先对缺失的 Cb/Cr 上采样/插值补回每像素,再逆变换
R = Y + 1.402(Cr−128)
G = Y − 0.344(Cb−128) − 0.714(Cr−128)
B = Y + 1.772(Cb−128)。
(3) 线性插值。已知 Y₀=80、Y₁=120、Y₄=200,缺 Y₂、Y₃。用 Y₁ 与 Y₄ 间线性插值(跨 3 步,每步 (200−120)/3≈26.67):Y₂ ≈ 120+26.67 ≈ 146.7,Y₃ ≈ 120+2×26.67 ≈ 173.3。(若按最近邻复制则 Y₂=Y₃=120;线性插值更精确,答题写明依据。)
