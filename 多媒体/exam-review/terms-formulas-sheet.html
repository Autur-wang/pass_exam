★ 计算题必背公式 TOP（考前 60 秒）

  • 数据量 = W × H × B / 8（图像）；× fps × 时长（视频）
  • 4:2:0 = 1.5 B/px，4:2:2=2，4:4:4=3
  • H = −Σ pi·log2 pi（熵，编码下界）
  • PSNR = 10·log10(255² / MSE)
  • SQNR ≈ 6.02N + 1.76 dB；Nyquist fs ≥ 2f_max
  • MAD = (1/N²)Σ|T − R|（运动估计）
  • JPEG：DC-DPCM 差分 + AC-RLC (run,level)+EOB
  • AP = Σ(命中 P@k) / 相关总数；mAP = AP 均值
  • CNN 输出 (N + 2P − F)/S + 1
  • 算术编码：区间逐符号缩窄，取区间内最短二进制小数

L02 · 图像数据

核心名词

  • 像素 Pixel — 图像最小离散单位
  • 位平面 Bitplane — 8-bit 图可拆成 8 个 1-bit 平面，最高位含主结构
  • 灰度图 Gray — 每像素 8-bit，0–255 共 256 级
  • 直方图 Histogram — 统计各灰度值的像素数；均衡化提对比度
  • 颜色查找表 CLUT — 8-bit 索引映射到 24-bit 真彩
  • 抖动 Dithering — 用空间分辨率换强度分辨率，1-bit 模拟灰度

核心公式

  • Y = 0.299R + 0.587G + 0.114B — RGB 转灰度（G 权重最大）
  • Size = W × H × B / 8 (Byte) — B = 每像素 bit；单位换算用 1024
  • 色数 = 256³ ≈ 16.8M — 24-bit RGB 可表色数
  • C=1−R, M=1−G, Y=1−B — RGB → CMY（归一化）

L03 · 颜色空间

核心名词

  • 加色/减色 Additive/Subtractive — RGB 叠加发光（屏幕）；CMY 吸光（印刷）
  • CIE XYZ CIE XYZ — 设备无关参考色空间，Y 表亮度
  • HSV HSV — 色相/饱和度/明度，贴合直觉
  • YCbCr YCbCr — Y 亮度 + Cb/Cr 色度，YUV 的数字版
  • Gamma 校正 Gamma — 补偿显示器非线性，γ ≈ 2.2
  • 色域 Gamut — 设备可表颜色子集，色度图上的三角形

核心公式

  • L = V^γ — Gamma 显示；γ≈2.2（CRT/sRGB）
  • 4:4:4=3 B/px，4:2:2=2，4:2:0=1.5 — 色度二次采样每像素字节（4:2:0 效率最高=50%）
  • R = Y + 1.402(Cr−128) — YCbCr → R
  • G = Y − 0.344(Cb−128) − 0.714(Cr−128) — YCbCr → G
  • B = Y + 1.772(Cb−128) — YCbCr → B

L04 · 视频基础

核心名词

  • 隔行/逐行 Interlaced/Progressive — 奇偶场交替 vs 逐行更新
  • NTSC / PAL NTSC/PAL — 29.97 fps（美日）/ 25 fps（欧中）
  • 色度二次采样 Chroma Subsampling — 4:2:0/4:2:2/4:4:4，省带宽
  • HDTV / 4K HDTV/UHDTV — 1920×1080 / 3840×2160

核心公式

  • Size = W × H × fps × 时长 × B/px — 未压缩视频数据量
  • 码率 = 像素数 × fps × BPP — BPP = bits per pixel
  • 1080p@30 4:2:0 ≈ 93 MB/s — ≈ 744 Mbps 原始码率

L05 · 音频基础

核心名词

  • 奈奎斯特定理 Nyquist — fs ≥ 2·f_max 才能无混叠还原
  • 假频 Aliasing — 采样不足导致高频折叠为低频
  • SNR / SQNR SNR/SQNR — 信噪比 / 量化信噪比
  • PCM / DPCM PCM/DPCM — 采样→量化→编码 / 编码差值
  • 响度/音调/音色 Loudness/Pitch/Timbre — 对应振幅/频率/频谱结构

核心公式

  • fs ≥ 2·f_max — 奈奎斯特采样率下限
  • SNR = 10·log10(Ps/Pn) = 20·log10(Vs/Vn) — 功率 10、电压 20，别记混
  • SQNR ≈ 6.02N + 1.76 (dB) — 每加 1 bit ≈ +6 dB
  • 音频码率 = 采样率 × 量化bit × 通道数 — 单位 bps
  • 电话 8k×8 = 64 kbps；CD 44.1k×16×2 = 1411 kbps — 两个必记数字

L06 · 无损压缩

核心名词

  • 信息熵 Entropy — η=−Σpi·log2 pi，编码码长下界
  • Huffman 编码 Huffman — 频次合并二叉树、变长前缀码
  • 算术编码 Arithmetic — 区间缩窄，可逼近熵
  • 游程编码 RLC — (run, value) 对，适合长串重复
  • LZW LZW — 动态建字典，GIF/TIFF 用
  • Kraft 不等式 Kraft — Σ2^−li ≤ 1，前缀码存在条件

核心公式

  • I(s) = −log2 p(s) — 自信息（bit）
  • η = −Σ pi·log2 pi — 信息熵 = 平均自信息
  • l̄ = Σ pi·li — 平均码长
  • η ≤ l̄ < η + 1 — Huffman 码长界（≥η，非等于）
  • CR = B0 / B1 — 压缩比，>1 即压缩

L07 · 有损压缩

核心名词

  • 均方误差 MSE — (1/N)Σ(xi−yi)²
  • 峰值信噪比 PSNR — 衡量失真，越大越好
  • 量化 Quantization — 连续值离散化，有损唯一来源
  • 标量/向量量化 Scalar/Vector — 逐元素 / 块级码本匹配
  • 离散余弦变换 DCT — 实数变换、能量集中于低频，本身可逆无损
  • 率失真 R(D) — 给定失真 D 下的最小码率

核心公式

  • MSE = (1/N)·Σ(xi − yi)² — 均方误差
  • PSNR = 10·log10(255² / MSE) — 8-bit 峰值 255
  • F̂(u,v) = round(F(u,v) / Q(u,v)) — 量化（Q 为步长）
  • D=0 ⇒ R=η — 率失真曲线下凸，零失真=无损极限

L08 · JPEG

核心名词

  • DC / AC 系数 DC/AC — (0,0) 块均值 / 其余 63 个高频
  • Z 字扫描 ZigZag — 8×8 块按 Z 序读出，集中低频
  • 量化 Quantization — JPEG 五步中唯一不可逆步骤
  • 量化因子 qf — 控制精细度，qf 越高越精细

核心公式

  • DC-DPCM: d = DC_cur − DC_prev — 相邻块 DC 差分编码
  • AC-RLC: (run, level) … EOB — run=前导 0 个数，level=非零值
  • qf≥50: scaling = (100−qf)/50 — qf=50→1（标准表）
  • qf<50: scaling = 50/qf — qf=25→2（更粗糙）

L09 · 运动补偿

核心名词

  • 运动补偿 / 估计 MC / ME — 用 MV 预测当前块 / 搜索最优 MV
  • 运动向量 MV — (dx, dy)，块在参考帧的偏移
  • 宏块 Macroblock — 16×16 Y + 8×8×2 色度（4:2:0）
  • 2D 对数搜索 2D-log — 步长逐轮减半的快速搜索，避免全搜索

核心公式

  • MAD = (1/N²)·Σ|T(i,j) − R(i,j)| — 块匹配代价（绝对值，非平方）
  • 搜索窗口 = (2p+1)² — p=搜索半径；p=15 → 961 个候选
  • 2D-log：中心+上下左右 5 点，步长减半 — 取 MAD 最小者为新中心至收敛

L10 · 帧类型与标准

核心名词

  • I / P / B 帧 Intra/Predictive/Bi — 帧内 / 前向预测 / 双向预测
  • H.261 / H.264 H.26x — 视频会议 / AVC 省 50% 码率
  • MPEG-1/2/4 MPEG — VCD / DVD / 对象编码协议族
  • 视频对象平面 VOP — MPEG-4 基于对象编码单元

核心公式

  • I : P : B = 7 : 20 : 50 — 压缩比（B 帧最高）
  • 平均 ≈ 27 : 1 — MPEG 典型压缩水平
  • B 帧需前后两参考帧 — 压缩比最高但延迟高

L11 · 检索与特征

核心名词

  • 基于内容检索 CBIR — 按图像内容特征检索
  • 语义鸿沟 Semantic Gap — 底层特征 vs 人类语义的差异
  • Harris 角点 Harris — R=det−k·trace²，不抗尺度
  • SIFT / SURF SIFT/SURF — 128 维 / 64 维，抗尺度旋转
  • MSER / DoG / RANSAC MSER/DoG/RANSAC — 仿射不变 / 尺度空间 / 鲁棒估计

核心公式

  • R = det(M) − k·trace(M)² — Harris 响应，k≈0.04–0.06
  • SIFT 4×4×8 = 128 维；SURF 4×4×4 = 64 维 — 描述子维度
  • Precision = 命中数 / 返回数 — 查准率
  • Recall = 命中数 / 相关总数 — 查全率
  • AP = Σ(命中位置 P@k) / 相关总数 — 平均精度；mAP = 各查询 AP 的均值

L12 · 深度学习 / CNN

核心名词

  • 卷积核 / 步长 / 填充 Kernel/Stride/Padding — F×F 权重 / 滑动步幅 / 边缘补 0
  • 局部感受野 / 参数共享 Receptive Field / Weight Sharing — 只连局部 + 同核扫全图，减参数
  • 池化 Pooling — Max/Avg 降采样，扩大感受野
  • ReLU / Dropout ReLU/Dropout — max(0,x) / 随机丢弃防过拟合
  • 经典网络 AlexNet/VGG/GoogleNet/ResNet — 60M / 138M / 5M / 25M 参数

核心公式

  • 输出 = (N + 2P − F) / S + 1 — 卷积输出边长（2P 别漏算一边）
  • 池化 = (N − F) / S + 1 — 无填充
  • 参数量 = (F·F·C + 1)·K — C 输入通道，K 卷积核数
  • 224, F=3, S=1, P=1 → 224 — same 卷积保持尺寸
