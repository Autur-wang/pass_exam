CNN 基础:卷积 · 池化 · 输出尺寸计算

上一讲我们手工设计特征(边缘、角点、SIFT);这一讲把"设计特征"这件苦差交给网络自己去学。整门课的最后一块拼图,也是计算题里最好拿分的一类——套公式即可。

直觉类比

L11 里我们像老工匠:亲手雕出"该看哪里"的模板(梯度、SIFT 描述子),再拿去匹配。CNN 则像招进一批学徒——你不告诉它边缘长什么样,只给它成千上万张带标签的图和一个"错了就挨罚"的损失函数,它自己反复调整卷积核,直到底层学出边缘、中层学出纹理、高层学出"猫脸""车轮"。特征不再靠人拍脑袋,而是从数据里长出来的。

1.三种积木:卷积层 · 池化层 · 全连接层

一个典型 CNN 就是这三种层交叉堆叠而成。先把每种积木的定义钉死:

卷积层 (Convolutional Layer)
用一个小的卷积核 / 滤波器(如 3×3)在输入图上滑动,逐位置做加权求和,产出一张特征图 (feature map)。两大法宝:局部关联(每个输出只连接输入的一小片)与参数共享(同一个核扫遍全图)——正是这两点把全连接网络"参数爆炸→过拟合"的病治好了。stride 步长、padding 填充、depth 通道数是它的三个旋钮。
池化层 (Pooling Layer)
对特征图做下采样,只保留主要特征。Max pooling取窗口最大值,Average pooling取平均。作用:减少参数与计算量、防止过拟合、提升泛化。池化没有可学参数——它只是缩图。
全连接层 (Fully Connected Layer)
相邻两层所有神经元两两相连,通常位于网络尾部,把提炼好的特征映射到类目得分。整张网里参数量通常最大的就是它——VGG 的 138M 参数大多堆在这。
感受野 (Receptive Field)
某个输出神经元"能看到"的原始输入区域大小。越往深层,单个神经元的感受野越大,看到的东西越"全局"。这就是为什么小卷积核多层堆叠能覆盖大范围——深度换视野。
卷积:核在输入上滑动,一次算出输出一个像素。把 3×3 卷积核对准输入左上角的红框区域(它"看到"的这一小片就是感受野),核里 9 个权重与框内 9 个数逐元素相乘再求和,得到输出图左上角那一个像素(图中的 ?)。核向右滑一格(stride=1)算下一个,滑遍全图就得到整张 3×3 输出。无填充(pad=0)时输出比输入小:(5−3)/1+1=3。整张图只用这一个核的同一套权重——这就是参数共享。
池化:把每个 2×2 窗口压成一个值,只留主特征。输入按 2×2 划成四块,Max pooling 每块取最大值:左上块 {1,3,5,6}→6,右上 {2,4,7,8}→8,左下 {3,2,1,0}→3,右下 {1,2,4,3}→4。4×4 一步降为 2×2,尺寸减半。若换成 Average pooling 就把"取最大"改成"取平均"。池化没有可学参数,纯粹是缩图——目的是减计算、防过拟合、增强对微小平移的鲁棒性。

3.CNN 为什么能"自动学特征"

回到 L11 的对比。手工特征(SIFT、HOG、颜色直方图)的流程是:人先定义"什么算特征"→ 提取 → 再喂给分类器。它的天花板由设计者的想象力决定,而且换个任务就得换一套特征。

CNN 把"特征提取"与"分类"合并成一条可端到端训练的管道。浅层卷积核自动收敛到边缘/颜色检测器,深层组合出物体部件——这套层级表示不是人写死的,而是被损失函数(交叉熵、MSE 等)一路反向传播"逼"出来的。数据越多、网络越深,它能学到的抽象层次越高。这就是为什么 2012 年 AlexNet 一出,手工特征时代基本落幕。

代价也很清楚:CNN 是数据饥渴且算力昂贵的黑箱,可解释性远不如手工特征。考试里问"CNN 相比传统方法的优势/代价",答这两点即可。

4.两条必背公式

计算题的全部分数都藏在这两条式子里,务必背到条件反射:

① 卷积输出尺寸
设输入边长 N、卷积核边长 F、填充 p、步长 s,则输出特征图边长:
输出 = (N + 2p − F) / s + 1
无 padding 时 p = 0,退化为 (N − F)/s + 1。结果须为整数,否则说明尺寸/步长不匹配。
② 卷积层参数量
设卷积核 F×F、输入通道数 C、卷积核个数(输出通道)K,则:
参数量 = (F · F · C + 1) · K
那个 +1 是每个卷积核自带的一个偏置 bias。输出通道数 = 卷积核个数 K。
把公式每一项对上图:输出边长 O = ⌊(W−K+2P)/S⌋+1。灰格是两侧各补的 padding P,中间 5 个是原始输入宽 W;红框是核宽 K=3 首次覆盖的位置,金色箭头是它每次向右跳的步长 S=2。核在"加了 padding 的 W+2P=7 格"上滑动,每步跳 S,能落几次就出几个像素:(7−3)/2+1=3。怎么读:先算分子 W−K+2P,再除步长 S,最后才 +1(算头一次落点)。边界:结果要向下取整 ⌊·⌋,除不尽说明核在边缘"够不着",最后一步被舍掉。
例题 · 输出尺寸 + 参数量一起算

输入图像 32×32×3(高×宽×通道),用 10 个 5×5 的卷积核,步长 s=1,填充 p=2。求输出特征图尺寸与该卷积层参数量。

  1. 列出已知:N=32,F=5,p=2,s=1,输入通道 C=3,卷积核个数 K=10。
  2. 套公式①算输出边长:(N + 2p − F)/s + 1 = (32 + 2×2 − 5)/1 + 1 = (32 + 4 − 5) + 1 = 31 + 1 = 32。
  3. 拼上通道:输出通道数 = 卷积核个数 = 10,故输出特征图为 32×32×10。(padding=2 恰好把尺寸"撑回"原大小,这也是 p=(F−1)/2 保持同尺寸的常用技巧。)
  4. 套公式②算参数量:每个核 5×5×3 = 75 个权重,加 1 个偏置 = 76;共 10 个核。
  5. 合计:(5×5×3 + 1) × 10 = 76 × 10 = 760 个参数。
结论:输出特征图 32×32×10;该卷积层参数量 760。注意参数量与输入图多大无关(参数共享),这正是卷积省参数的根源。
自测题

某卷积层输入为 7×7,卷积核 3×3,步长 s=2,填充 p=1。输出特征图的边长是多少?

  1. 3
  2. 4
  3. 5
  4. 6
答案:B　4

直接代入公式①:(N + 2p − F)/s + 1 = (7 + 2×1 − 3)/2 + 1 = (7 + 2 − 3)/2 + 1 = 6/2 + 1 = 3 + 1 = 4。
易错点:先算分子 7+2−3=6,再除以步长 2 得 3,最后才 +1 得 4。若忘记 padding(当 p=0)会算成 (7−3)/2+1=3,恰好落入干扰项 A——所以务必看清题目给没给 padding。

5.更多计算例题:五种常考题型

上面那道是"尺寸+参数一起算"的标准型。下面按考试常见的五种变体各来一道,每道都把套公式的顺序写死。做题口诀:先分子 N−F+2p,再除步长 s,最后才 +1;除不尽向下取整。

例题 2 · 无填充卷积(尺寸会缩小)

输入 28×28,卷积核 5×5,步长 s=1,不填充(p=0)。求输出边长。

  1. 已知 N=28,F=5,p=0,s=1。
  2. 代公式①:(N − F + 2p)/s + 1 = (28 − 5 + 0)/1 + 1 = 23 + 1 = 24。
输出 24×24。无填充时,核在边缘"够不着",每条边各丢 F−1=4 个像素 → 尺寸从 28 缩到 24。这正是 VGG 要靠 p=1 补回尺寸的原因。
例题 3 · 池化的输出尺寸

输入特征图 24×24,做 2×2 最大池化,步长 s=2。求输出边长。

  1. 池化沿用同一条尺寸公式,但几乎总是无填充(p=0):输出 = (N − F)/s + 1。
  2. 代入 N=24,F=2,s=2:(24 − 2)/2 + 1 = 22/2 + 1 = 11 + 1 = 12。
输出 12×12,尺寸减半。记住:F=2、s=2 的池化就是"边长除以 2"。池化不改变通道数,也没有参数——只缩高宽。
例题 4 · 多层串联,追踪特征图尺寸(大题最爱)

输入 32×32,依次经过:Conv1(5×5, p=2, s=1)→ Pool1(2×2, s=2)→ Conv2(3×3, p=1, s=1)→ Pool2(2×2, s=2)。求最终特征图边长。

关键纪律:一层一层来,上一层的输出就是下一层的输入。列一张表最不容易错:

层操作输入算式输出
Conv15×5, p2, s132(32 − 5 + 4)/1 + 132
Pool12×2, s232(32 − 2)/2 + 116
Conv23×3, p1, s116(16 − 3 + 2)/1 + 116
Pool22×2, s216(16 − 2)/2 + 18
最终 8×8。规律看得很清楚:带 p=(F−1)/2 的卷积保持尺寸不变(5×5 配 p2、3×3 配 p1),真正让特征图变小的是池化(每次减半:32→16→8)。所以数"缩了几次",基本就是数"经过几个 stride=2 的池化"。
尺寸逐层追踪流水线。五个方块是每一步后的特征图,大小按边长画:32 → 32 → 16 → 16 → 8。蓝红两次 Conv 都因为配了 p=(F−1)/2 而尺寸不变(只在换特征、加通道);两次 Pool(s=2)各把边长砍半。所以"最终多大"的答案,几乎只由经过几个 stride=2 的下采样决定——本例两次,32 → 16 → 8。做题提醒:一层写一行,上一行输出填进下一行输入,绝不跳步心算。
例题 5 · AlexNet 首层的大步长卷积

AlexNet 输入 227×227×3,第一层用 96 个 11×11 卷积核,步长 s=4,p=0。求输出特征图尺寸。

  1. 代公式①:(227 − 11 + 0)/4 + 1 = 216/4 + 1 = 54 + 1 = 55。
  2. 输出通道 = 卷积核个数 = 96,故输出 55×55×96。
输出 55×55×96。大步长(s=4)是"一上来就猛缩图"的手段:一步就把 227 压到 55。有的教材写成 224×224 配 p=2,则 ⌊(224−11+4)/4⌋+1 = ⌊54.25⌋+1 = 55,靠向下取整同样得 55。
例题 6 · 全连接层的参数量(看它为何最臃肿)

某网络最后一张特征图为 7×7×512,把它展平后接一个 4096 个神经元的全连接层。求这一层的参数量。

  1. 展平:7 × 7 × 512 = 25088 个输入。
  2. 全连接=每个输出神经元与所有输入相连,各带 1 个偏置:参数 = 输入数 × 输出数 + 输出数 = 25088 × 4096 + 4096。
  3. 计算:= 4096 × (25088 + 1) = 4096 × 25089 ≈ 1.028 × 10⁸。
约 1.03 亿(≈102.8M)个参数——就这一层。对比例题 1 的卷积层只有 760 个:全连接层没有参数共享,一展平就"参数爆炸"。这正是 VGG 138M 参数大半堆在 FC、而 GoogleNet/ResNet 索性去掉 FC 的原因。
经典考点:两个 3×3 为什么能替一个 5×5

把两个 3×3 卷积叠起来,第二层每个神经元透过第一层能"看到"输入的 5×5 区域——感受野等效于一个 5×5 卷积。但参数上(单通道单核):一个 5×5 = 25 个权重,两个 3×3 = 2×9 = 18 个,更省;而且中间多插了一次非线性激活(ReLU),表达力更强。这就是 VGG"只用小核堆深"的核心论据——考简答题常问,记住"同感受野、更少参数、更多非线性"九个字。

自测题 2 · 池化尺寸

输入特征图 16×16,做 3×3 池化,步长 s=1,p=0(重叠池化)。输出边长是多少?

  1. 13
  2. 14
  3. 15
  4. 16
答案:B　14

池化同样套 (N − F)/s + 1 = (16 − 3)/1 + 1 = 13 + 1 = 14。
易错点:这里 s=1(重叠池化)而非常见的 s=2,所以尺寸只小一点点,不是减半。别一看"池化"就条件反射写"除以 2"——先看步长。

自测题 3 · 多层串联

输入 64×64,先过 Conv(3×3, p=1, s=1),再过 Max Pool(2×2, s=2)。输出边长是多少?

  1. 16
  2. 62
  3. 32
  4. 31
答案:C　32

一层一层来:
Conv 3×3, p1, s1:(64 − 3 + 2)/1 + 1 = 63 + 1 = 64——配了 p=1,尺寸不变。
Pool 2×2, s2:(64 − 2)/2 + 1 = 31 + 1 = 32——减半。
陷阱:D 选项 31 是"忘了最后 +1";B 62 是"卷积忘加 padding"。牢记卷积那步因 p=1 保持 64 不变,只有池化把它砍到 32。

串联计算不翻车的三条纪律

① 一层一行,绝不心算跳步——上一层输出照抄进下一层输入。
② 先认"尺寸变不变":卷积配 p=(F−1)/2 就保尺寸,池化(s=2)必减半,stride>1 的卷积也会缩。
③ +1 永远最后做,除不尽向下取整——这两处是丢分重灾区。
